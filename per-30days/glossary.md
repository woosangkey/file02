## 핵심 공식

| 공식 | 내용 | 배운 날 |
|---|---|---|
| PER | 주가 ÷ EPS = 시가총액 ÷ 지배주주 순이익 | Day 1 |
| EPS | 지배주주 순이익 ÷ 가중평균 발행주식수 | Day 1 |
| 이익수익률 | EPS ÷ 주가 = 1 ÷ PER | Day 2 |
| 트레일링 PER | 주가 ÷ 최근 4개 분기 EPS 합(TTM) | Day 3 |
| 포워드 PER | 주가 ÷ 향후 12개월 예상 EPS | Day 3 |
| 희석 EPS | (순이익 + 전환 시 절감 이자 등) ÷ (기본 주식수 + 잠재주식수) | Day 4 |
| CAPE (실러 PER) | 주가 ÷ 최근 10년 평균 실질 EPS | Day 5 |
| 그레이엄 넘버 | √(22.5 × EPS × BPS) | Day 5 |
| 지수 PER | 구성 종목 시가총액 합 ÷ 순이익 합 | Day 6 |
| 고든 모형 | P₀ = D₁ ÷ (r − g) | Day 8 |
| 정당 포워드 PER | 배당성향 ÷ (r − g) | Day 8 |
| 정당 트레일링 PER | 배당성향 × (1 + g) ÷ (r − g) | Day 8 |
| 기본 성장률 | g = ROE × 유보율 = ROE × (1 − 배당성향) | Day 9 |
| ROE를 넣은 정당 PER | (1 − g ÷ ROE) ÷ (r − g) | Day 9 |
| 정당 PBR | (ROE − g) ÷ (r − g), PBR ≈ PER × ROE | Day 9 |
| PEG | PER ÷ (EPS 성장률 × 100) | Day 10 |
| 할인율 | r = 무위험금리 + 주식 위험 프리미엄 | Day 11 |
| 연준 모형(단순형) | 이익수익률 vs 10년 국채 금리 | Day 11 |
| 정상화 PER | 주가 ÷ 사이클 평균 EPS (또는 평균 이익률 × 현재 매출) | Day 12 |
| PSR | 시가총액 ÷ 매출 = PER × 순이익률 | Day 13 |
| EV | 시가총액 + 순차입금 (+ 비지배지분 등) | Day 13 |
| EV/EBITDA | EV ÷ (영업이익 + 감가상각비) | Day 13 |
| 레버리지 한계 하락률 | 1 ÷ 레버리지 배수 (증거금률) | Day 17, 20 |
| 회복 필요 상승률 | 1 ÷ (1 − 하락률) − 1 | Day 17 |
| 고PER 정당화 초과 성장률 | (PER_A ÷ PER_시장)^(1/n) − 1 | Day 17 |
| 순현금 제외 PER | (시가총액 − 순현금) ÷ (순이익 − 세후 이자수익) | Day 23 |
| 소유주 이익 | 순이익 + 감가상각비 − 유지 설비투자 − 운전자본 증가 | Day 24 |
| 필요 EPS 성장률 | [(1 + 기대수익률)ⁿ × 현재 PER ÷ 도달 PER]^(1/n) − 1 | Day 27 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 가치 함정 | 싸 보이지만 이익 감소·지배구조 문제 등으로 계속 싼 상태에 머무는 주식 |
| 거품법(Bubble Act) | 1720년 영국 의회가 허가 없는 주식회사 설립을 제한한 법 (1825년 폐지) |
| 경상 이익 (정상 이익) | 일회성 손익을 걷어 내고 보통의 해에 반복될 것으로 보는 이익 |
| 고든 성장모형 | 배당이 일정 비율로 영원히 성장한다고 가정한 배당할인모형 |
| 니프티 피프티 | 1970년대 초 미국 기관투자자가 선호한 50개 안팎의 고PER 우량 성장주 |
| 더 큰 바보 이론 | 비싸게 사도 더 비싸게 사 줄 사람이 있으면 이익을 본다는 생각 |
| 동물적 본능 | 케인스가 말한, 계산보다 자생적 낙관에 좌우되는 경제 행동 |
| 레버리지 | 빚을 이용해 투자 규모를 키우는 것 |
| 미스터 마켓 | 그레이엄이 만든 비유. 매일 변덕스러운 값을 부르는 시장이라는 동업자 |
| 미인대회 비유 | 케인스가 주식 투자를, 남들이 뽑을 얼굴을 맞히는 대회에 비유한 것 |
| 민스키 모멘트 | 빚에 기댄 자산 가격 상승이 멈추며 강제 매도와 급락이 시작되는 순간 |
| 배당성향 | 순이익 중 배당으로 지급하는 비율 |
| 비생산적 자산 | 튤립·금처럼 스스로 현금흐름을 만들어 내지 않는 자산 |
| 소유주 이익 | 버핏이 1986년 주주서한에서 정의한, 주인이 사업 유지 후 가져갈 수 있는 현금 |
| 스팩(SPAC) | 비상장 기업 인수를 목적으로 먼저 상장하는 회사 |
| 연준 모형 | 시장 이익수익률과 국채 금리를 비교하는 시장의 통칭 (연준 공식 모형 아님) |
| 원 디시전 주식 | 한 번 사면 팔 필요가 없다고 여겨진 니프티 피프티 종목의 별칭 |
| 유보율 | 순이익 중 배당하지 않고 회사에 남기는 비율 (= 1 − 배당성향) |
| 유지 설비투자 | 현재의 생산 능력과 경쟁력을 유지하는 데 필요한 설비투자 |
| 이익 서프라이즈 / 쇼크 | 실제 이익이 예상치보다 높음 / 낮음 |
| 이익수익률 | PER의 역수. 주가 대비 이익의 비율 |
| 정당한 PER (내재 PER) | 성장·위험·배당성향 등 펀더멘털로 계산한 PER |
| 정상화 PER | 사이클 평균 이익으로 계산한 PER |
| 조정 EPS (비GAAP) | 회사가 일부 비용을 임의로 제외해 만든 이익 지표 |
| 지배주주 순이익 | 연결 순이익 중 모회사 주주에게 귀속되는 몫 |
| 컨센서스 | 여러 애널리스트 예상치의 평균 또는 중간값 |
| 코리아 디스카운트 | 한국 기업이 비슷한 해외 기업보다 낮은 배수로 거래되는 현상 |
| 폰지 금융 | 민스키의 세 번째 차입 단계. 이자도 못 갚고 자산 가격 상승에 기대어 빌림 |
| 해자(moat) | 경쟁자가 쉽게 따라 하지 못하게 하는 사업의 지속적 우위 |
| 희석 | 신주 발행·전환 등으로 기존 주주의 주당 몫이 줄어드는 것 |
| CAPE | 경기조정 PER. 10년 평균 실질 이익 기준 PER (실러 PER) |
| EBITDA | 이자·세금·감가상각 전 이익 |
| EPS | 주당순이익 |
| EV | 기업가치. 주주와 채권자 몫을 합친 사업 전체의 값 |
| FCFE | 주주 잉여현금흐름 |
| FOMO | 놓칠까 봐 두려운 마음 (Fear of Missing Out) |
| PBR | 주가순자산비율 |
| PEG | PER을 이익 성장률로 나눈 값 |
| PSR | 주가매출비율 |
| ROE | 자기자본이익률 |
| TTM | 최근 12개월(4개 분기) 합계 |
