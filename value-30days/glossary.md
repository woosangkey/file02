## 핵심 공식

| 공식 | 내용 | 배운 날 |
|---|---|---|
| 안전마진 | (내재가치 − 주가) ÷ 내재가치 | Day 1 |
| 매수 상한 가격 | 내재가치 × (1 − 원하는 안전마진) | Day 1 |
| 그레이엄 방어적 기준 | PER ≤ 15, PBR ≤ 1.5 (PER × PBR ≤ 22.5) | Day 2 |
| 순유동자산가치(NCAV) | 유동자산 − 총부채 / 넷넷: 시가총액 < NCAV × 2/3 | Day 3 |
| 재무상태표 등식 | 자산 = 부채 + 자본 | Day 4 |
| PER / 이익수익률 | 주가 ÷ EPS / EPS ÷ 주가 | Day 5 |
| PBR | 주가 ÷ BPS | Day 5 |
| 배당수익률 / 배당성향 | DPS ÷ 주가 / 배당금 ÷ 순이익 | Day 5 |
| EV/EBITDA | (시가총액 + 순차입금) ÷ (영업이익 + 감가상각비) | Day 5 |
| ROE 듀폰 분해 | 순이익률 × 총자산회전율 × 재무레버리지 | Day 6 |
| PER·PBR·ROE 관계 | PBR = PER × ROE | Day 6 |
| 간이 FCF | 영업활동 현금흐름 − 설비투자 | Day 8 |
| FCFF | 영업이익 × (1 − 세율) + 감가상각비 − 설비투자 − 운전자본 증가 | Day 8 |
| CAPM | 자기자본비용 = 무위험이자율 + β × 시장위험프리미엄 | Day 9 |
| WACC | E 비중 × 자기자본비용 + D 비중 × 세전 부채비용 × (1 − 세율) | Day 9 |
| 터미널 가치 | 마지막 해 FCF × (1 + g) ÷ (WACC − g) | Day 10 |
| 주당 가치 (DCF) | (FCF 현재가치 합 + TV 현재가치 − 순차입금) ÷ 주식 수 | Day 10 |
| 고든 성장모형 | 가치 = D₁ ÷ (r − g), 기대수익률 r = D₁ ÷ 주가 + g | Day 11 |
| 정당한 PBR | (ROE − g) ÷ (r − g) | Day 12 |
| RIM (잔여이익 영구 지속) | BPS + (ROE − r) × BPS ÷ r | Day 13 |
| 그레이엄 성장주 공식 | EPS × (8.5 + 2g) | Day 13 |
| 그레이엄 넘버 | √(22.5 × EPS × BPS) | Day 13 |
| 자사주 소각 후 EPS | 순이익 ÷ (기존 주식 수 − 소각 주식 수) | Day 18 |
| 지주사 NAV 할인율 | 1 − 시가총액 ÷ (보유 지분 가치 − 순차입금) | Day 20 |
| 손실 회복 필요 수익률 | 1 ÷ (1 − 하락률) − 1 | Day 25 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 가치 팩터 | 싼 주식이 비싼 주식보다 장기적으로 수익률이 높았던 현상, 또는 그 특성 |
| 가치 함정 | 지표상 싸 보이지만 가치 자체가 줄어들어 계속 싼 상태로 머무는 주식 |
| 경기조정 PER (CAPE) | 주가 ÷ 10년 평균 실질이익. 로버트 실러가 널리 알림 |
| 경제적 해자 | 경쟁자로부터 높은 수익성을 오래 지켜 주는 구조적 경쟁우위 |
| 고든 성장모형 | 배당이 일정하게 성장한다고 가정한 배당할인모형 |
| 기업가치 제고 계획 | 밸류업 프로그램에서 상장사가 자율 공시하도록 권장하는 계획 |
| 내재가치 | 기업이 앞으로 만들어 낼 현금흐름의 현재가치 합 |
| 넷넷 | 시가총액이 순유동자산가치의 2/3보다 낮은 주식 |
| 능력범위 | 투자자가 충분히 이해할 수 있는 사업의 범위 |
| 담배꽁초 투자 | 평범한 기업을 청산가치보다 아주 싸게 사는 방식 (버핏의 표현) |
| 듀폰 분해 | ROE를 순이익률·자산회전율·재무레버리지로 나눠 보는 분석 |
| 마법공식 | 이익수익률과 자본수익률 순위를 더해 고르는 그린블랫의 방법 |
| 미스터 마켓 | 매일 감정적으로 값을 부르는 시장을 의인화한 그레이엄의 비유 |
| 민감도 분석 | 할인율·성장률 같은 가정을 바꿔 가며 가치의 범위를 보는 방법 |
| 방어적 투자자 | 노력을 적게 들이고 큰 실수를 피하려는 투자자 (그레이엄의 분류) |
| 배당성향 | 순이익 중 배당으로 지급하는 비율 |
| 배당할인모형(DDM) | 미래 배당의 현재가치 합으로 주식 가치를 구하는 방법 |
| 사실 수집(Scuttlebutt) | 고객·경쟁사·공급업체 등에서 정보를 모으는 피셔의 방법 |
| 상대가치평가 | 비교 기업의 멀티플을 적용해 가치를 구하는 방법 |
| 순차입금 | 차입금 − 현금성자산 |
| 안전마진 | 추정 가치보다 충분히 싸게 사서 확보하는 오차 흡수 여유 |
| 영구성장률 | 예측기간 이후 현금흐름이 영원히 성장한다고 가정하는 비율 |
| 운전자본 | 영업에 묶이는 자금 (매출채권 + 재고 − 매입채무 등) |
| 이익수익률 | EPS ÷ 주가 (또는 EBIT ÷ EV) |
| 이익의 질 | 이익이 현금으로 뒷받침되고 반복 가능한 정도 |
| 잉여현금흐름(FCF) | 필요한 투자 후 주주·채권자에게 돌려줄 수 있는 현금 |
| 자기자본비용 | 주주가 요구하는 수익률 |
| 자본배분 | 이익을 재투자·인수·배당·자사주 매입 등에 나눠 쓰는 경영 결정 |
| 잔여이익모형(RIM) | 순자산 + 요구수익률을 넘는 초과이익의 현재가치로 가치를 구하는 방법 |
| 적합성 원칙 | 고객 상황에 맞지 않는 상품을 권유하지 말라는 판매 원칙 |
| 정당한 PBR | ROE·요구수익률·성장률로 계산한 이론적 PBR |
| 주주 이익(Owner Earnings) | 순이익 + 감가상각 − 유지에 필요한 설비투자 (버핏의 개념, 요지) |
| 지속계수 | RIM에서 초과이익이 시간이 지나며 줄어드는 정도를 반영하는 계수 |
| 지주사 할인 | 지주회사 시가총액이 보유 지분 가치(NAV)보다 낮은 현상 |
| 촉매 | 가격이 가치로 수렴하게 만드는 사건 (실적 개선, 주주환원, 지배구조 변화 등) |
| 코리아 디스카운트 | 한국 주식이 비슷한 해외 기업보다 낮은 평가를 받는 현상 |
| 터미널 가치(TV) | 예측기간 이후 모든 현금흐름의 가치 |
| 플로트 | 보험사가 보험금 지급 전까지 운용할 수 있는 자금 |
| 할인율 | 미래 현금흐름을 현재가치로 바꿀 때 쓰는 요구수익률 |
| 효율적 규모 | 시장이 작아 새 경쟁자가 들어오기 어려운 해자 유형 |
| BPS | 주당순자산 (자기자본 ÷ 주식 수) |
| CAPM | 자본자산가격결정모형. 자기자본비용 추정에 사용 |
| DCF | 현금흐름할인법 |
| EBITDA | 이자·세금·감가상각 전 이익 (영업이익 + 감가상각비) |
| EPS | 주당순이익 (순이익 ÷ 주식 수) |
| EV | 기업가치 (시가총액 + 순차입금) |
| HML | 장부가/시가 상위(싼) 주식 수익률 − 하위(비싼) 주식 수익률 |
| NAV | 순자산가치. 지주사 분석에서는 보유 지분 가치 − 순차입금 |
| NCAV | 순유동자산가치 (유동자산 − 총부채) |
| PBR | 주가순자산비율 |
| PER | 주가수익비율 |
| ROE | 자기자본이익률 (순이익 ÷ 자기자본) |
| ROIC | 투하자본이익률 (세후 영업이익 ÷ 투하자본) |
| WACC | 가중평균자본비용 |
