## 핵심 공식과 원칙

| 공식·원칙 | 내용 | 배운 날 |
|---|---|---|
| 총지출 | 지출 = 돈 + 신용 | Day 2 |
| 지출과 소득 | 한 사람의 지출 = 다른 사람의 소득 | Day 2 |
| 세 가지 힘 | 경제 = 생산성 추세 + 단기 부채 사이클 + 장기 부채 사이클 | Day 4 |
| 부채/소득 비율 변화 | 1년 뒤 비율 = 현재 비율 × (1 + 부채 증가율) ÷ (1 + 소득 증가율) | Day 6 |
| 세 가지 경험칙 | ① 부채 < 소득 증가 ② 소득 < 생산성 증가 ③ 생산성 향상 | Day 7 |
| 아름다운 디레버리징 | 명목 성장률 > 명목 금리 | Day 9 |
| 부채비율 변화 근사 | ≈ (금리 − 성장률) × 부채비율 | Day 9 |
| 정부 이자 부담 | 이자비용/세수 = (부채/GDP × 평균 이자율) ÷ (세수/GDP) | Day 20 |
| 위험 기여 (상관 0) | (비중 × 변동성)² | Day 23 |
| 위험 균등 비중 | 비중A × 변동성A = 비중B × 변동성B | Day 23 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 기축통화 | 국제 거래·외환보유액에 가장 많이 쓰이는 통화 |
| 단기 부채 사이클 | 약 5~8년 주기로 반복되는 신용 확장·수축, 중앙은행 금리로 조절 |
| 디레버리징 | 소득 대비 부채 부담을 줄이는 과정 |
| 디플레이션형 부채위기 | 자국 통화 부채 위기, 불황과 물가 하락 |
| 리스크 패리티 | 금액이 아니라 위험을 균등하게 배분하는 전략 |
| 버블 | 자산 가격이 전통적 기준을 크게 넘고 레버리지 매수로 부풀려진 상태 |
| 브리지워터 | 레이 달리오가 1975년 세운 헤지펀드 |
| 빅 사이클 | 부채·내부 질서·외부 질서가 함께 움직이는 장기(수십~수백 년) 사이클 |
| 생산성 | 같은 자원으로 더 많이 만들어 내는 능력, 장기 성장의 원천 |
| 스태그플레이션 | 성장 둔화와 물가 상승이 함께 나타나는 상태 |
| 신용 | 미래에 갚기로 하고 지금 쓰는 구매력 (동시에 부채가 생김) |
| 아름다운 디레버리징 | 디플레이션·인플레이션 수단의 균형으로 부채비율을 낮추는 과정 |
| 올웨더 | 네 가지 경제 환경에 고르게 대비하는 브리지워터의 전략 (1996년) |
| 외부 질서 | 국가 간 부와 권력의 질서 |
| 인플레이션형 부채위기 | 외화 부채·해외 자금 의존 위기, 통화 가치 폭락과 물가 급등 |
| 장기 부채 사이클 | 수십 년에 걸쳐 부채가 소득보다 빠르게 쌓였다가 디레버리징으로 끝나는 사이클 |
| 내부 질서 | 한 나라 안의 부와 권력 분배 질서 |
| 다섯 가지 전쟁 | 무역·경제, 기술, 지정학, 자본, 군사 전쟁 |
| 화폐 발행 | 중앙은행이 돈을 찍어 자산을 사는 것, 인플레이션적 디레버리징 수단 |
| MP1 / MP2 / MP3 | 금리 조절 / 양적완화 / 재정·통화 협력 |
| 성배(Holy Grail) | 상관관계가 낮은 좋은 수익원 약 15개로 위험을 크게 줄이는 분산 원리 |
