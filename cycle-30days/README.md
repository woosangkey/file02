# 경제 사이클 30일 완성 — 레이 달리오의 프레임으로

> 하루 30분, 30일 동안 레이 달리오가 정리한 **경제 기계의 작동 원리 → 부채위기와 디레버리징 → 빅 사이클과 세계 질서 → 사이클에 견디는 투자와 상담**까지 익히는 학습 자료입니다.
> 목표: ① 지금 경제가 사이클의 어디쯤인지 스스로 점검하는 투자자, ② 고객에게 "위기가 오나요?"라는 질문에 겁주지도 안심시키지도 않고 구조적으로 답하는 상담역.
> 함께 보면 좋은 자료: [금리 30일 완성](../rates-30days/README.md) · [외환 30일 완성](../forex-30days/README.md)

## 하루 30분 사용법

| 시간 | 할 일 |
|---|---|
| 0–12분 | **핵심 개념** 읽기 |
| 12–20분 | **예시·계산** 직접 따라 하기 |
| 20–25분 | **투자자 / 상담역 포인트** 정리 → 노트에 한 줄 요약 |
| 25–30분 | **확인 문제** 풀고 정답 확인 (정답은 문제 바로 아래) |

## 꼭 알아둘 점

- 이 자료는 레이 달리오의 공개 저작과 영상을 바탕으로 **핵심 개념을 학습용으로 요약·재구성**한 것입니다. 원문 인용이 아니며, 세부 표현은 원전과 다를 수 있습니다.
- 달리오의 프레임은 **하나의 관점**이지 정설이 아닙니다. Day 27에서 비판과 한계를 함께 다룹니다.
- 예시의 숫자는 **이해를 돕기 위한 가정값**입니다. 실제 통계는 한국은행 ECOS, IMF, BIS, 미국 FRED 등에서 확인하세요. (이 자료는 2026년 10월 기준으로 작성했습니다.)
- 이 자료는 학습용이며 특정 상품의 투자를 권유하지 않습니다.
