## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 가속컴퓨팅 | 특정 계산을 GPU 같은 전용 장치로 빠르게 처리하는 방식 |
| 거꾸로 일하기 (Working Backwards) | 제품을 만들기 전 출시 보도자료와 예상 질문(PR/FAQ)부터 쓰는 아마존의 방식 |
| 고객 집착 (Customer Obsession) | 경쟁자보다 고객에게서 출발하는 아마존의 첫 번째 리더십 원칙 |
| 두 종류의 문 | 되돌리기 어려운 한 방향 문(1종) 결정과 되돌릴 수 있는 양방향 문(2종) 결정 |
| 매몰비용 | 이미 써서 되돌릴 수 없는 비용. 앞으로의 판단에 영향을 주면 안 됨 |
| 반대하되 실행 (Disagree and commit) | 동의하지 않아도 결정이 나면 전력으로 실행하는 원칙 |
| 생존 편향 | 살아남은 사례만 보고 결론을 내리는 오류 |
| 성장 마인드셋 | 능력은 노력과 학습으로 자란다는 믿음 (캐럴 드웩) |
| 승계형 CEO | 창업자가 아닌, 전임자의 뒤를 이은 전문경영인 CEO |
| 실적발표 콜 (Earnings Call) | 분기 실적 발표 후 경영진이 애널리스트 질문에 답하는 전화 회의 |
| 앱 추적 투명성 (ATT) | 앱이 사용자를 추적하려면 허락을 받도록 한 애플의 2021년 기능 |
| 제1원리 사고 | 관행이 아니라 가장 기본이 되는 사실에서 다시 생각하는 방법 |
| 주주서한 | CEO가 매년 주주에게 경영 철학과 성과를 설명하는 편지 |
| 지배구조 | 경영진을 견제하고 감독하는 이사회·주주의 구조 |
| 차등의결권 | 주식마다 의결권을 다르게 주는 구조. 창업자가 지분보다 큰 의결권을 가짐 |
| 창업자 모드 (Founder Mode) | 창업자가 세부 사항까지 직접 챙기는 경영 방식 (폴 그레이엄, 2024) |
