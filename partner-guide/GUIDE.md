# 작성 지침 — 『고액자산가 세무·재무 자문 연결 가이드』(투자자문사 상담사용)

## 배경
- 독자: 증권사(프리즘) 제휴 **투자자문사 상담사**. 세무 전문가가 아님.
- 목적: 상담 중 고액자산가를 만났을 때 **회계법인 더위즈**(세무·재무 자문)로 연결할지 판단하고, 고객에게 왜 필요한지 정확히 설명할 수 있을 만큼의 지식을 갖추는 것.
- 더위즈 서비스: 4단계(Stage Ⅰ 초도 진단 2주 200만 원 → Ⅱ 쟁점 의견서 2~3주 300만~1,000만 원 → Ⅲ 종합 컨설팅 3~5개월 2,000만~5,000만 원+성공보수 15~20% → Ⅳ 정기 자문 Ⅳ-a 기장 월 15~100만 / Ⅳ-b 상시자문 월 30~200만, 모두 VAT 별도). Ⅰ→Ⅲ 6개월 내 이행 시 Ⅰ 보수 차감, Ⅲ+Ⅳ 번들 시 첫 12개월 20% 할인. 법무(등기·주주간계약서·소송)는 제휴 로펌.
- 6개 자문 영역: 01 법인 구조(신설 vs 리모델링·지주형/자법인형·지배구조 재편) / 02 부동산(현물출자·포괄양수도·매매·과점주주 간주취득세) / 03 금융투자(금융소득종합과세·법인계좌·해외주식·건강보험료) / 04 인출·배당(급여·상여·배당·퇴직금·가지급금·가수금·차등배당) / 05 부의 이전(가족법인 증여·저가양수도·초과배당·명의신탁 정리) / 06 상속(가업상속공제·가업승계 과세특례·비상장주식 평가) + 해외이주(홍콩·싱가포르, 국외전출세, 대주주 판정·비상장주식 평가 모니터링).

## 각 장 구성 (content/<id>.md, 한 장 = A4 6~9쪽 분량, 본문 9,000~14,000자)
첫 줄: `# 0N. 장 제목` 다음 줄 `<p class="lead">한 줄 요약</p>`
1. `## 1. 이 서비스는 무엇을 해결하나` — 고객의 고민 언어로.
2. `## 2. 꼭 알아야 할 개념` — 용어 표(용어 | 쉬운 뜻 | 상담 포인트).
3. `## 3. 언제 유리하고 언제 불리한가` — **자산·소득 상황 기준**(금액대, 소득 구조, 가족 구성, 보유 기간 등)으로. 유리/불리 VS 박스 필수. 가능하면 "대략 이 정도부터 검토 가치" 같은 손익분기 감각을 숫자로(단, 개별 검토 필요 명시).
4. `## 4. 2026년 핵심 세법·제도` — 표(항목 | 내용 | 근거 조문). 2025년 말 국회 통과·2026년 시행 개정 반영. 미확정 개정안은 "국회 심의 중" 표시.
5. `## 5. 숫자로 보는 예시` — 가상 고객 1~2명, 개인 vs 법인 등 비교 계산 표. 계산은 반드시 검산(파이썬). "단순화한 예시" 명시.
6. `## 6. 상담 중 이런 신호가 보이면` — 고객 발언/자산 신호 체크리스트 + 확인 질문 6~10개(그대로 물어볼 수 있는 문장).
7. `## 7. 리스크와 흔한 오해` — 과세관청 쟁점, 사후관리 위반, 부당행위계산부인 등.
8. `## 8. 더위즈로 연결하기` — 권장 Stage, 고객에게 받아 둘 자료 목록, 예상 산출물.
9. `## 9. 상담사가 할 수 있는 말 / 하면 안 되는 말` — 표. (세무 결론 단정·절세 보장·세무대리 행위는 금지. 세무사법상 세무상담·신고대리는 세무사 업무)
10. 마지막: 한 장 요약 박스 `<div class="box summary"><div class="box-title">한 장 요약</div>…</div>`

## 컴포넌트 (HTML 그대로)
- 박스: `<div class="box"><div class="box-title">제목</div>…</div>`, 요약 `<div class="box summary">…`
- 한눈에 보기: `<div class="glance"><div class="g-title">제목</div><div class="g-body"> … </div></div>`
  - 흐름 `<div class="flow"><div class="step"><b>1</b>설명</div>…</div>`
  - 카드 `<div class="cards c2|c3"><div class="card"><b>제목</b>설명</div>…</div>` (큰 숫자 `<span class="big">…</span>`)
  - 비교 `<div class="vs"><div class="side"><b>유리한 경우</b><ul><li>…</li></ul></div><div class="mid">VS</div><div class="side alt"><b>불리한 경우</b><ul>…</ul></div></div>`
  - 체크리스트 `<ul class="check"><li>…</li></ul>`
- 경고 박스: `<div class="box warn"><div class="box-title">주의</div>…</div>`
- 표는 마크다운 표, 바로 위에 `<p class="caption">[표 N-n] 제목</p>`.
- HTML 블록 안에서는 마크다운 문법 쓰지 말 것.

## 사실 확인 (매우 중요)
- 모든 세율·한도·요건·조문은 **WebSearch로 2026년 10월 현행 기준 확인**(국세청·법제처·재정경제부·행정안전부(지방세)·주요 회계법인/언론). 2025.12 국회 통과 세법개정(법인세율 조정 등) 반영 여부를 반드시 확인.
- 확인 불가·출처 상충은 단정하지 말고 "확인 필요"로 표기. 지어내지 않는다.
- 장 끝에 `<div class="endnote">※ 기준: 2026년 10월. 근거: … (출처명)</div>`.
- 다른 장 파일 수정 금지, git 금지.
