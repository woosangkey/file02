## 핵심 공식

| 공식 | 내용 | 배운 날 |
|---|---|---|
| 주가 분해 | 주가 = EPS × PER → 주가 수익률 ≈ EPS 성장 + PER 변화 | Day 1 |
| 이익의 복리 | n년 뒤 EPS = 현재 EPS × (1 + g)ⁿ | Day 1 |
| 매출 성장 분해 | (1 + 시장 성장률) × (1 + 점유율 변화율) − 1, (1 + 판매량 증가율) × (1 + 가격 상승률) − 1 | Day 2 |
| CAGR | (끝 값 ÷ 시작 값)^(1/n) − 1 | Day 3 |
| 주당 성장률 | (1 + 이익 성장률) ÷ (1 + 주식 수 증가율) − 1 | Day 3, 18 |
| 공헌이익 | 매출 − 변동비 | Day 4 |
| LTV | 월 ARPU × 공헌이익률 ÷ 월 이탈률 | Day 4 |
| CAC 회수 기간 | CAC ÷ (월 ARPU × 공헌이익률) | Day 4 |
| NRR | (시작 ARR + 확장 − 축소 − 이탈) ÷ 시작 ARR | Day 5 |
| GRR | (시작 ARR − 축소 − 이탈) ÷ 시작 ARR | Day 5 |
| 연 이탈률 | 1 − (1 − 월 이탈률)¹² | Day 5 |
| Rule of 40 | 매출 성장률(%) + FCF 마진(%) ≥ 40 | Day 5 |
| 바텀업 TAM | 고객 수 × 고객당 연간 지출 | Day 6 |
| PEG | PER ÷ 이익 성장률(%) | Day 11 |
| 린치의 배당 반영 지표 | (이익 성장률 + 배당수익률) ÷ PER | Day 11 |
| 텐배거 필요 수익률 | 10^(1/n) − 1 | Day 11 |
| 손실 회복 상승률 | 1 ÷ (1 − 손실률) − 1 | Day 12 |
| 연결 가능한 쌍 | n(n − 1) ÷ 2 | Day 13 |
| EV | 시가총액 + 차입금 − 현금 | Day 15 |
| PSR과 PER | PSR = PER × 순이익률 | Day 15 |
| 간단 역DCF | 필요한 미래 이익 = 현재 시가총액 × (1 + 요구수익률)ⁿ ÷ 성숙 PER | Day 15 |
| 고든 성장 모형 | 가치 = 내년 현금흐름 ÷ (r − g) | Day 16 |
| SBC 반영 FCF | 보고된 FCF − SBC | Day 18 |
| 최대 비중 | 계좌 손실 한도 ÷ 가정 최대 하락률 | Day 23 |
| 포트폴리오 영향 | 성장주 비중 × 성장주 하락률 | Day 24 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 가이던스 | 회사가 직접 밝히는 향후 실적 전망 |
| 가치주 | 이익·자산에 비해 주가가 싼 주식 |
| 간접(양면) 네트워크 효과 | 한쪽 참여자가 늘면 다른 쪽 참여자에게 가치가 커지는 현상 |
| 고성장주 | 린치의 분류. 연 20~25% 이상 빠르게 성장하는 회사 |
| 공헌이익 | 매출에서 변동비를 뺀 이익. 고정비를 갚는 데 보태는 돈 |
| 기업 생애주기 | 도입 → 성장 → 성숙 → 쇠퇴. 로 프라이스 성장주 이론의 바탕 |
| 네트워크 효과 | 사용자가 늘수록 모든 사용자에게 가치가 커지는 현상 |
| 니프티 피프티 | 1970년대 초 미국에서 "가격과 관계없이 사도 된다"고 여겨진 우량 성장주 50여 종목 |
| 리밸런싱 | 쏠린 자산 비중을 목표 비중으로 되돌리는 것 |
| 메트칼프의 법칙 | 네트워크 가치가 사용자 수의 제곱에 비례한다는 경험칙 |
| 바텀업 추정 | 고객 수 × 고객당 지출처럼 아래에서부터 쌓아 올린 시장 추정 |
| 성장 함정 | 성장이 예상보다 빨리 둔화되어 이익 전망과 멀티플이 함께 떨어지는 상황 |
| 성장주 | 매출·이익이 평균보다 빠르게, 오래 늘 것으로 기대되는 주식 |
| 생존자 편향 | 살아남은 성공 사례만 보고 실패 사례를 무시하는 오류 |
| 스커틀버트 | 고객·경쟁사·납품업체 등에게서 정보를 모으는 피셔의 조사 방법 |
| 영업 레버리지 | 고정비 비중이 커서 매출 변화보다 이익 변화가 크게 나타나는 현상 |
| 역DCF | 현재 주가에서 시장이 가정한 성장률을 거꾸로 구하는 방법 |
| 위스퍼 넘버 | 공식 컨센서스보다 높은, 시장이 속으로 기대하는 실적 |
| 유기적 성장 | 인수·합병 없이 기존 사업에서 나온 성장 |
| 이중 타격(더블 펀치) | 이익 전망 하향과 PER 하락이 동시에 와서 주가가 크게 떨어지는 것 |
| 잔존가치 | DCF에서 예측 기간 이후 모든 현금흐름의 가치 |
| 적합성 원칙 | 고객의 목적·재산·경험·감내도에 맞지 않는 상품을 권유하지 않는 원칙 |
| 주식 듀레이션 | 주식 가치의 금리 민감도. 가치가 먼 미래에 몰릴수록 큼 |
| 처분효과 | 이익 난 주식은 빨리 팔고 손실 난 주식은 오래 들고 있는 경향 |
| 캐즘 | 초기 수용자와 초기 다수 사이의 큰 틈 (제프리 무어) |
| 컨센서스 | 애널리스트 실적 추정치의 평균 |
| 텐배거 | 산 가격의 10배가 된 주식 (피터 린치) |
| 테마 ETF | AI·2차전지 등 특정 이야기에 맞는 종목을 모은 ETF |
| 희석 | 주식 수 증가로 기존 주주의 지분 몫이 줄어드는 것 |
| ARR | 연간 반복 매출 |
| ARPU | 고객 1명당 평균 매출 |
| CAC | 고객 획득 비용 |
| CAGR | 연평균 복합 성장률 |
| CAN SLIM | 윌리엄 오닐의 종목 선정법 (이익 성장 + 가격 추세) |
| EV/Sales | 기업가치 ÷ 매출 |
| GRR | 총매출 유지율 (확장 제외) |
| LTV | 고객 생애 가치 |
| NRR | 순매출 유지율 (확장 포함) |
| PEG | PER ÷ 이익 성장률 |
| PSR | 주가매출비율 (시가총액 ÷ 매출) |
| Rule of 40 | 매출 성장률 + 이익률이 40 이상이면 건강하다는 SaaS 경험칙 |
| S커브 | 새 기술 보급이 느림 → 빠름 → 포화로 이어지는 곡선 |
| SaaS | 구독형 소프트웨어 |
| SBC | 주식보상 (주식·스톡옵션·RSU로 지급하는 보수) |
| TAM / SAM / SOM | 전체 시장 / 유효 시장 / 획득 가능 시장 |
