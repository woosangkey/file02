# 2026 세법·제도 검수 지침 (검수 에이전트 공통)

대상: /home/user/file02/corp-book/content/*.md (책 『법인 컨설팅 100문 100답』, 기준일 2026년 10월)

## 절차
1. 담당 주제의 키워드로 **content 폴더 전체를 grep** 하여, 담당 파일 외 다른 꼭지에 나온 같은 주제 서술도 모두 찾는다(꼭지 간 수치가 서로 다르면 안 된다).
2. 수치·요율·한도·요건·시행일·제도 존재 여부 등 **검증 가능한 사실 주장**을 모두 목록화한다.
3. 각 주장을 WebSearch(필요시 WebFetch)로 확인한다. 우선순위: 법제처(law.go.kr)·국세청·기획재정부·금융위원회·금융감독원·한국은행·국민연금공단·예금보험공사·청약홈/국토교통부·한국거래소 등 **공식 출처** > 주요 언론 > 기타. 2025~2026년 세법개정(2025년 말 국회 통과분 포함, 2026년 시행분)과 2026년 하반기 정부 세법개정안(2027년 시행 예정, 미확정)을 구분한다.
4. 판정:
   - **정확**: 그대로 둔다.
   - **오류/구버전**: 본문을 Edit 도구로 직접 고친다(문체 유지, 최소 수정, 표·박스 형식 유지). 같은 내용이 다른 꼭지에도 있으면 함께 고친다.
   - **불확실**(공식 확인 불가, 출처 상충, 미확정 개정안): 단정 표현을 "~로 알려져 있다/ 국회 심의 중/ 가입 전 확인" 형태로 완화한다.
5. 계산 예시가 바뀐 수치에 의존하면 다시 계산해 고친다.
6. 결과를 `/home/user/file02/corp-book/review/<담당주제>.md` 에 표로 기록:
   `| 파일:위치 | 원문 요지 | 판정(정확/수정/완화) | 수정 후 | 근거(출처명·URL·발표일) |`
   마지막에 "인쇄 전 사람이 최종 확인할 항목" 목록.

## 주의
- 다른 에이전트도 동시에 다른 주제로 같은 파일을 편집할 수 있다. 편집 직전 해당 부분을 다시 Read 하고, 작고 정확한 Edit만 한다. 파일 전체를 Write로 덮어쓰지 않는다.
- 담당 주제 밖 내용은 고치지 않는다(발견하면 리포트의 '타 주제 발견 사항'에 적기).
- build.py, style.css, toc.py 수정 금지. git 금지.
