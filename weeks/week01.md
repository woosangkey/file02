# 1주차 · 입학 첫날, 하루코와 만나다

**Day 1–7** · 문법: `〜です / 〜ですか`

> 쇼호쿠 고등학교에 막 입학한 사쿠라기 하나미치는 복도에서 한 여학생에게 말을 걸린다. 그녀가 바로 아카기 하루코. 첫눈에 반한 사쿠라기는 잔뜩 긴장한 채 첫인사를 나눈다.

**이번 주 목표:** 처음 만난 사람에게 인사하고 「〜です」로 자기 이름을 말할 수 있다. 「〜ですか」로 간단히 확인 질문을 할 수 있다.

**이번 주 가나:** あ행·か행 (あいうえお かきくけこ)

## 7일 학습 계획

### Day 1 — 장면·단어 (약 20분)

- [ ] 이번 주 장면 설명과 목표를 읽는다

- [ ] 단어 10개를 듣고 하나당 3번씩 소리 내어 따라 한다

- [ ] 단어를 노트에 한 번씩 쓰고 뜻을 가린 채 셀프 테스트한다

- [ ] (가나가 있는 주) 이번 주 가나를 5번씩 쓰며 소리 낸다


### Day 2 — 문법·핵심표현 (약 25분)

- [ ] 문법 설명을 읽고 예문 4개를 듣고 따라 한다

- [ ] 예문을 바꿔서 '나에 관한' 문장 3개를 노트에 쓴다

- [ ] 핵심표현 5개를 듣고 3번씩 따라 말한다

- [ ] 어제 단어를 뜻만 보고 일본어로 말해 본다


### Day 3 — 듣기 (약 20분)

- [ ] 대본을 가린 채 대화를 2번 듣는다

- [ ] 듣기 퀴즈 3문제를 푼다

- [ ] 대본을 보면서 다시 듣고, 못 들은 부분에 표시한다

- [ ] 표시한 문장만 3번 더 듣는다


### Day 4 — 쉐도잉 (약 25분)

- [ ] 한 줄씩 듣고 멈춘 뒤 똑같이 따라 말한다 (전체 2회)

- [ ] 대본을 보며 소리와 동시에 겹쳐 말한다 (쉐도잉 3회)

- [ ] 한국어 번역만 보고 일본어로 말해 본다

- [ ] 가장 어려운 문장 1개를 외운다


### Day 5 — 말하기 (약 25분)

- [ ] 역할극: 캐릭터 하나를 골라 내 대사를 직접 말한다 (상대 대사는 음성)

- [ ] 역할을 바꿔서 한 번 더 한다

- [ ] 말하기 과제를 1분 동안 휴대폰으로 녹음한다

- [ ] 녹음을 듣고 고칠 점 1가지를 메모한다


### Day 6 — 받아쓰기·쓰기 (약 30분)

- [ ] 받아쓰기 3문장 (들리는 대로 쓰고 정답 확인)

- [ ] 쓰기 과제를 노트에 쓴다

- [ ] 모범 답안과 비교해 고친 뒤 소리 내어 읽는다


### Day 7 — 주간 복습 (약 25분)

- [ ] 단어 셀프 테스트: 10개 중 8개 이상이면 통과

- [ ] 대화문 전체를 대본 없이 말해 본다 (막히면 대본 보기)

- [ ] 지난주 핵심표현 5개를 다시 말해 본다

- [ ] 말하기·듣기·쓰기 자기평가(1~5점)를 기록한다

## 문법: 〜です / 〜ですか

명사 뒤에 「です」를 붙이면 '~입니다'라는 정중한 문장이 됩니다. 끝에 「か」를 붙인 「〜ですか」는 '~입니까?'라는 질문이 되며, 일본어에서는 물음표 대신 「。」를 쓰는 경우가 많습니다. 한국어의 '-입니다/-입니까'와 거의 같은 감각으로 쓸 수 있습니다. 이름 뒤에는 「さん」(~씨)을 붙이고, 남학생에게는 「くん」을 붙이기도 합니다. 단, 자기 이름에는 「さん」을 붙이지 않는 점에 주의하세요.

| 예문 | 읽기 | 뜻 |
|---|---|---|
| 桜木です。 | さくらぎです。 | 사쿠라기입니다. |
| 晴子さんですか。 | はるこさんですか。 | 하루코 씨입니까? |
| はい、学生です。 | はい、がくせいです。 | 네, 학생입니다. |
| 先生ですか。 | せんせいですか。 | 선생님이십니까? |

## 말하기 과제

사쿠라기가 되어 하루코에게 처음 인사해 보세요. 「はじめまして」→ 이름 「〜です」→「よろしくおねがいします」 순서로, 이번에는 내 이름으로도 말해 보세요.

## 쓰기 과제

나를 소개하는 인사말을 2~3문장으로 쓰세요. 「はじめまして」, 「〜です」, 「よろしくおねがいします」를 꼭 넣으세요.
