# 월별 커리큘럼 JSON (study/syllabus/mNN.json)
```json
{
  "month": 1,
  "title": "월 주제 (20자 이내)",
  "level": "입문·중급 | 중급 | 상급 | 하이엔드",
  "goal": "이 달의 학습 목표 한 문단 (150~250자)",
  "outcomes": ["월말에 할 수 있게 되는 것 3~4개"],
  "project": "월말 종합 과제 설명 (100~200자)",
  "days": [
    {"day": 1, "type": "L", "title": "일차 제목 (30자 이내)",
     "topics": ["세부 주제 2~3개, 각 25자 이내"],
     "deliverable": "그날의 실습·산출물 한 줄 (40자 이내)"}
  ]
}
```
- type: L=학습일(새 개념), D=실전 드릴(계산·케이스 문제 집중), R=주간 복습(요약노트·모의테스트·오답정리)
- days 는 지정된 날짜 범위의 모든 날을 순서대로, 지정된 type 그대로.
- JSON 문자열 안 큰따옴표 금지(「」 사용).
