# 하루 데이터 규격 — data/mNN.json

파일 하나 = 한 달. JSON 객체이며 키는 Day 번호 문자열, 값은 하루 데이터:

```json
{
  "1": {
    "day": 1,
    "part": "文法形式の判断",
    "title": "〜や否や — '~하자마자'의 문어체",
    "topic": "지문 주제를 한국어로 짧게 (예: 신제품 출시와 품절 소동)",
    "passage": {
      "ja": "오늘의 독해 지문. N1 수준 논설·수필·기사·안내문 등 새로 쓴 글 220~380자. 오늘 문법을 1회 이상 자연스럽게 포함.",
      "ko": "자연스러운 한국어 번역"
    },
    "lines": [
      {"who": "女", "ja": "…", "kana": "…", "ko": "…"}
    ],
    "words": [
      {"w": "顕著", "r": "けんちょ", "ko": "현저함, 두드러짐"}
    ],
    "grammar": {
      "point": "〜や否や",
      "form": "동사 사전형 + や否や",
      "desc": "한국어 설명 4~6문장: 의미, 접속, 뉘앙스(문어/구어), 주의점(주어 제약, 의지문 불가 등), 시험에서 노리는 함정.",
      "ex": [ {"ja": "…", "kana": "…", "ko": "…"} ]
    },
    "compare": {
      "a": "〜や否や",
      "b": "〜たとたん(に)",
      "note": "두 표현의 차이를 한국어 2~3문장으로",
      "exA": "a를 쓴 짧은 일본어 예문",
      "exB": "b를 쓴 짧은 일본어 예문"
    },
    "mission": "쓰기 또는 말하기 과제 (한국어). 오늘 문법·어휘를 써서 구체적으로.",
    "missionEx": {"ja": "모범 답안", "kana": "…", "ko": "…"},
    "quiz": [
      {"type": "文法形式の判断", "q": "ベルが鳴る（　　）、生徒たちは教室を飛び出した。", "choices": ["や否や", "次第", "とたん", "うちに"], "a": 0, "why": "한국어 해설: 정답 이유 + 오답이 안 되는 이유"}
    ]
  }
}
```

## 개수 규칙 (정확히)
- `lines` 4~6줄: 청해용 미니 대화(2~3명). 자연스러운 회화체, 오늘 문법이나 어휘를 1회 이상 포함. `who`는 男, 女, 男の学生, 女の学生, 部長, 課長, 店員, 客, 司会, 先生, 医者 등 JLPT 청해식 화자.
- `words` 정확히 8개: 그 달의 어휘 테마에서 N1 수준 어휘. 같은 단어를 다른 날과 중복하지 말 것(같은 파일 안에서).
- `grammar.ex` 정확히 3개.
- `quiz` 정확히 3문제, 각 보기 4개, `a`는 0~3 정답 인덱스:
  1. 오늘 문법 문제 (`文法形式の判断` 또는 `文の組み立て`). 文の組み立て는 문장에 `＿＿ ＿＿ ★ ＿＿`를 넣고 ★ 자리에 들어갈 것을 고르게 한다.
  2. 어휘 문제: 그 달의 시험 파트 형식(漢字読み / 文脈規定 / 言い換え類義 / 用法). 用法은 보기 4개가 모두 문장이고 바르게 쓰인 것을 고른다.
  3. 오늘 지문 내용 문제(`内容理解`) — 단, 10·11월(Day 271~330)은 `聴解`: 오늘 대화를 듣고 푸는 문제(q에 질문만 쓰고 대화 내용은 쓰지 않음).
- 정답 위치(a)를 골고루 섞을 것 (0만 반복 금지).

## 표기 규칙
- `kana`: `ja` 전체를 히라가나로, 단어(어절) 사이를 띄어 쓴다. 가타카나어는 가타카나 그대로 둬도 됨. 조사 は/へ는 표기대로.
- `passage.ja`에는 kana를 주지 않는다(N1 독해 연습).
- 모든 지문·대화·예문은 새로 창작한다. JLPT 기출문제나 교재 문장을 옮기지 말 것.
- 일본어는 원어민이 쓴 듯 자연스럽고 정확해야 한다. 문법 설명은 정확해야 한다(틀린 설명은 치명적).
- JSON 유효성: 큰따옴표, 주석·끝 쉼표 금지. 일본어 인용은 「」.
