# 주차 데이터 작성 규격 (data/qN.json)

각 분기 파일은 13주 분량의 JSON 배열이다. 각 원소(주차)는 아래 형식을 정확히 따른다.

```json
{
  "week": 1,
  "title": "입학 첫날, 하루코와 만나다",
  "scene": "장면 설명 (한국어 2~3문장, 원작 줄거리를 요약만 하고 대사를 베끼지 않는다)",
  "goal": "이번 주 학습 목표 (한국어 1~2문장, '~할 수 있다' 형태)",
  "kana": "Q1에서만: 이번 주에 익힐 가나 행 (예: 'あ행·か행 (あいうえお かきくけこ)'). Q2 이후는 \"\"",
  "grammar": {
    "point": "〜です / 〜ですか",
    "explain": "한국어 설명 3~5문장. 만드는 법, 쓰임, 주의점. 한국어와 비교하면 좋다.",
    "examples": [ {"ja": "…", "yomi": "…", "ko": "…"} ]   // 정확히 4개
  },
  "vocab":    [ {"ja": "…", "yomi": "…", "ko": "…"} ],    // 정확히 10개
  "phrases":  [ {"ja": "…", "yomi": "…", "ko": "…"} ],    // 정확히 5개 (그대로 외워 쓸 핵심 표현)
  "dialogue": [ {"who": "桜木", "ja": "…", "yomi": "…", "ko": "…"} ], // 8~10줄
  "quiz": [ {"q": "대화 내용 듣기 문제 (한국어)", "a": "정답 (한국어 또는 일본어)"} ],  // 정확히 3개
  "dictation": [ "받아쓰기용 일본어 문장" ],  // 정확히 3개, dialogue/phrases에서 뽑는다
  "speaking": "말하기 과제 (한국어). 캐릭터가 되어/나에 대해 말하기 등 구체적으로",
  "writing": "쓰기 과제 (한국어). 분량 명시 (Q1: 2~3문장 → Q4: 200~400자)",
  "writingExample": {"ja": "모범 답안 일본어", "ko": "한국어 번역"}
}
```

## 필드 규칙
- `ja`: 자연스러운 일본어 (한자+가나 표기). Q1은 한자를 적게(초등 1~2학년 한자 위주), 분기가 오를수록 늘린다.
- `yomi`: `ja` 전체를 히라가나로 읽은 것 (가타카나 단어는 가타카나 그대로 두어도 됨). 띄어쓰기 없이, 문장부호는 유지.
- `ko`: 자연스러운 한국어 번역.
- `who`: 일본어 캐릭터 이름 (짧게). 사용 가능: 桜木, 晴子, 赤木, 流川, 宮城, 三井, 木暮, 安西先生, 彩子, 洋平, 仙道, 魚住, 牧, 藤真, 花形, 清田, 沢北, 深津, 記者, 店員, 先生(학교 선생님), 母.
- 화자 말투: 사쿠라기는 하루코·안자이 선생님께는 정중체(です·ます), 친구/라이벌에게는 거친 반말(おれ, 〜だ, 〜ぜ). 단, Q1(1~13주)은 학습자가 です·ます를 익히는 단계이므로 대화의 70% 이상을 정중체로 구성한다. Q2 18주부터 반말 비중을 자연스럽게 늘린다.
- 각 주의 대화에는 그 주의 문법 포인트가 최소 3회 등장해야 한다. 아직 배우지 않은 문법은 되도록 피한다 (불가피하면 핵심표현으로 통째로 익히게 한다).
- 저작권: 원작 대사를 그대로 옮기지 말고 모든 대화는 새로 창작한다. 예외적으로 실라버스에 명시된 짧은 명대사(「あきらめたらそこで試合終了ですよ」「左手はそえるだけ」「バスケがしたいです」 등 한 줄짜리)만 해당 주에 1회 인용 가능.
- 난이도 목표: 1년 후 일본 초등학교 고학년과 일상 대화 (JLPT N4~N3 회화). Q1=N5 입문, Q2=N5~N4, Q3=N4, Q4=N4~N3.
- JSON은 반드시 유효해야 한다 (주석 금지, 마지막 쉼표 금지, 큰따옴표 사용). 일본어 따옴표는 「」를 사용한다.
