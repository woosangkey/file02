## 핵심 공식

| 공식 | 내용 | 나온 대화 |
|---|---|---|
| ROE | 순이익 ÷ 자기자본 | 첫 번째 |
| ROA | 순이익 ÷ 총자산 | 첫 번째 |
| 3단계 듀퐁 | ROE = 순이익률 × 총자산회전율 × 재무레버리지 | 두 번째 |
| 3단계 (분수로) | ROE = (순이익 ÷ 매출) × (매출 ÷ 총자산) × (총자산 ÷ 자기자본) | 두 번째 |
| ROE와 ROA | ROE = ROA × 재무레버리지 | 두 번째 |
| 재무레버리지 | 총자산 ÷ 자기자본 = 1 + 부채비율 | 다섯 번째 |
| 레버리지 효과 | ROE = ROIC + (ROIC − 세후 이자율) × 부채 ÷ 자기자본 | 다섯 번째·여덟 번째 |
| 5단계 듀퐁 | ROE = (순이익 ÷ 세전이익) × (세전이익 ÷ 영업이익) × (영업이익 ÷ 매출) × (매출 ÷ 총자산) × (총자산 ÷ 자기자본) | 여섯 번째 |
| ROE 변화 분해 | ln(ROE 변화) = 각 조각의 ln(변화)의 합 | 여섯 번째 |
| ROIC | 세후 영업이익 ÷ 투하자본 | 여덟 번째 |
| 지속가능 성장률 | g = ROE × (1 − 배당성향) | 아홉 번째 |
| PBR 항등식 | PBR = PER × ROE | 아홉 번째 |
| 정당 PBR | (ROE − g) ÷ (r − g), 단 g < r | 아홉 번째 |
| 정당 PER | 배당성향 ÷ (r − g) | 아홉 번째 |
| 가계 듀퐁 (비유) | 저축 ÷ 순자산 ≈ 저축률 × (소득 ÷ 총자산) × (총자산 ÷ 순자산) | 열 번째 |

## 5단계 조각 읽는 법

| 조각 | 계산 | 높을수록 | 주의 |
|---|---|---|---|
| 세금부담률 | 순이익 ÷ 세전이익 | 세금 후 많이 남음 | 일시적 세금 혜택 |
| 이자부담률 | 세전이익 ÷ 영업이익 | 이자·영업외 손실이 적음 | 일회성 영업외 이익이 섞일 수 있음 |
| 영업이익률 | 영업이익 ÷ 매출 | 본업이 강함 | 업종 내 비교 |
| 총자산회전율 | 매출 ÷ 총자산 | 자산을 잘 씀 | 평균 자산 사용 권장 |
| 재무레버리지 | 총자산 ÷ 자기자본 | 빚이 많음 | 높을수록 **위험도 커짐** |

## 용어 정리

| 용어 | 뜻 |
|---|---|
| 자기자본 (자본총계) | 총자산에서 부채를 뺀 주주의 몫 |
| ROE (자기자본이익률) | 주주 돈 1원이 1년에 번 이익 |
| ROA (총자산이익률) | 자산 1원이 1년에 번 순이익 |
| ROIC (투하자본이익률) | 사업에 실제로 투입된 자본(이자 붙는 부채 + 자기자본 − 여유 현금)이 번 세후 영업이익 |
| 순이익률 | 매출 1원당 순이익 |
| 영업이익률 | 매출 1원당 본업 이익 |
| 총자산회전율 | 자산 1원으로 올린 매출 |
| 재무레버리지 (자기자본승수) | 자기자본 1원으로 굴리는 총자산 |
| 부채비율 | 부채 ÷ 자기자본 |
| 영업레버리지 | 고정비 때문에 매출 변화보다 이익 변화가 더 커지는 현상 |
| 이자보상배율 | 영업이익 ÷ 이자비용. 1 미만이면 영업으로 이자도 못 냄 |
| 순차입금 | 이자 붙는 부채 − 현금성 자산 |
| 자기자본비용 (r) | 주주가 요구하는 수익률. 추정치 |
| 가중평균자본비용 (WACC) | 주주와 채권자가 요구하는 수익률의 가중평균 |
| 배당성향 | 순이익 중 배당으로 나가는 비율 |
| 유보율 | 1 − 배당성향. 회사 안에 남겨 재투자하는 비율 |
| 지속가능 성장률 | 추가 차입·증자 없이 이익 유보만으로 가능한 자기자본 성장률 |
| PER | 주가 ÷ 주당순이익 |
| PBR | 주가 ÷ 주당순자산 |
| 자사주 매입 | 회사가 자기 주식을 사들이는 것. 자기자본이 줄어 ROE가 올라감 |
| 자본잠식 | 누적 손실로 자기자본이 납입자본보다 작아진 상태. 완전 자본잠식이면 자본이 0 이하 |
| 일회성 이익 | 자산 매각 이익 등 반복되지 않는 이익 |
| 페르미 추정 | 정확한 자료 없이 합리적 가정을 곱해 자릿수를 어림하는 방법 |
| 실사구시 (實事求是) | 사실에 근거해 진리를 찾는다는 뜻. 조선 후기 실학의 태도를 나타내는 말로 자주 쓰임 |
| 절용 (節用) | 씀씀이를 아낌. 『목민심서』 율기 편의 한 항목 |

## 업종별 전형적 패턴 (정성적, 일반적인 경향)

| 업종 | 순이익률 | 총자산회전율 | 재무레버리지 | ROE의 주된 원천 | 볼 것 |
|---|---|---|---|---|---|
| 명품·강한 브랜드 소비재 | 높음 | 낮음~중간 | 낮음 | 이익률 | 브랜드 지속성 |
| 소프트웨어·플랫폼 | 높음 | 낮음~중간 | 낮음 | 이익률 | 연구개발비 처리, 성장 투자 |
| 대형마트·편의점·도매 유통 | 낮음 | 높음 | 중간 | 회전율 | 가격 경쟁, 재고 |
| 일반 제조 | 중간 | 중간 | 중간 | 고르게 | 원가, 설비 가동률 |
| 반도체·화학·철강 (경기순환) | 호황 높음 / 불황 낮음 | 중간 | 낮음~중간 | 시기마다 다름 | 경기 한 바퀴 평균 |
| 항공·해운 | 낮음, 변동 큼 | 중간 | 높음 | 레버리지 | 유가·운임, 부채, 리스 |
| 전력·통신·인프라 | 중간 | 낮음 | 높음 | 레버리지 + 안정적 이익 | 규제, 금리 |
| 은행 | 업종 특성상 비교 어려움 | 매우 낮음 | 매우 높음 | 레버리지 | 자본비율, 대출 부실 |
| 보험 | 업종 특성상 비교 어려움 | 낮음 | 높음 | 레버리지 + 투자 수익 | 지급여력, 금리 |

- 위 표는 일반적인 경향이며, 같은 업종 안에서도 회사마다 크게 다를 수 있습니다.
