# 금리 30일 완성 — 투자 & 상담역 과정

> 하루 30분, 30일 동안 **금리의 기본 원리 → 통화정책과 시장 읽기 → 채권과 금리 상품 → 대출·자산배분 상담 실전**까지 익히는 학습 자료입니다.
> 목표: ① 금리 변화가 내 예금·채권·대출에 미치는 영향을 계산하는 투자자, ② 고객에게 금리 상품을 정확하고 적합하게 설명하는 상담역.
> 함께 보면 좋은 자료: [외환 30일 완성](../forex-30days/README.md) (금리와 환율은 같이 움직입니다)

## 하루 30분 사용법

| 시간 | 할 일 |
|---|---|
| 0–12분 | **핵심 개념** 읽기 |
| 12–20분 | **예시·계산**을 계산기로 직접 따라 하기 |
| 20–25분 | **투자자 / 상담역 포인트** 정리 → 노트에 한 줄 요약 |
| 25–30분 | **확인 문제** 풀고 정답 확인 (정답은 문제 바로 아래) |

> 팁: 매일 아침 한국 국고채 3년물·10년물, 미국 국채 2년물·10년물 금리 4개 숫자를 기록하세요. 30일 뒤에는 수익률곡선이 어떻게 움직였는지 스스로 그릴 수 있습니다.

## 꼭 알아둘 점

- 예시에 나오는 금리 숫자는 **계산 연습용 가정값**입니다. 실제 수치는 한국은행 경제통계시스템(ECOS), 금융투자협회 채권정보센터, 은행연합회 소비자포털에서 확인하세요.
- 세법, 예금자보호 한도, 대출 규제(DSR 등)는 자주 바뀝니다. 상담에 쓰기 전에 국세청, 예금보험공사, 금융위원회·금융감독원에서 **최신 기준을 꼭 다시 확인**하세요. (이 자료는 2026년 10월 기준으로 작성했습니다.)
- 이 자료는 학습용이며 특정 상품의 투자를 권유하지 않습니다.
