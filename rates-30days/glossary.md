| 단리 | 원리금 = 원금 × (1 + r × n) | Day 2 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 가산금리 | 대출금리에서 기준 지표금리 위에 더하는 금리 |
| 금리인하요구권 | 신용 상태가 좋아졌을 때 대출 금리 인하를 요구할 수 있는 권리 |
| 금융소득종합과세 | 이자·배당 소득이 연 2,000만 원을 넘으면 초과분을 종합소득에 합산 |
| 금통위 | 한국은행 금융통화위원회. 연 8회 기준금리 결정 |
| 기준금리 | 한국은행이 정하는 정책금리 (7일물 RP 매각 금리) |
| 꺾기 | 대출을 조건으로 다른 금융상품 가입을 강요하는 불공정 행위 |
| 듀레이션 | 채권 현금흐름의 가중평균 회수 기간, 금리 민감도 |
| 롤다운 | 남은 만기가 줄면서 적용 금리가 낮아져 채권 가격이 오르는 효과 |
| 만기수익률(YTM) | 만기까지 보유할 때의 연수익률 |
| 물가연동국채 | 원금이 물가에 연동되는 국채 |
| 바벨 전략 | 초단기와 장기 만기에 나눠 투자 |
| 볼록성 | 금리 변화에 대한 채권 가격 곡선의 휘어짐 |
| 빅스텝 / 베이비스텝 | 0.5%p / 0.25%p 금리 조정 |
| 사다리 전략 | 여러 만기에 균등하게 나눠 투자하고 만기 자금을 재투자 |
| 수익률곡선 | 만기별 금리를 이은 선 |
| 스트레스 DSR | 미래 금리 상승을 가정한 가산 금리를 더해 계산하는 DSR |
| 신용스프레드 | 회사채와 국고채의 금리 차이 |
| 신종자본증권 | 만기가 매우 길거나 없는 자본성 채권 (영구채) |
| 양적완화(QE) / 양적긴축(QT) | 중앙은행의 대규모 채권 매입 / 보유 채권 축소 |
| 유사수신행위 | 인가 없이 원금·고수익을 약속하며 자금을 모으는 불법 행위 |
| 장단기 금리차 | 장기 국채 금리 − 단기 국채 금리 |
| 점도표 | 연준 위원들의 향후 기준금리 전망 |
| 중도해지 이율 | 예금을 만기 전에 해지할 때 적용되는 낮은 금리 |
| 포워드 가이던스 | 중앙은행이 향후 정책 방향을 미리 알리는 것 |
| 표면금리(쿠폰) | 채권 액면 대비 매년 지급하는 이자율 |
| 할인채 / 할증채 | 액면보다 싸게 / 비싸게 거래되는 채권 |
| 후순위채 | 부도 시 일반 채권보다 변제 순위가 뒤인 채권 |
| BEI | 손익분기 인플레이션, 시장의 기대 물가 |
| bp (베이시스포인트) | 0.01%p |
| CD 금리 | 양도성예금증서 91일물 금리 |
| COFIX | 은행 자금조달비용지수, 변동금리 대출 기준 |
| DSR | 총부채원리금상환비율 (연간 원리금 상환액 ÷ 연소득) |
