# 🏀 슬램덩크로 배우는 일본어 회화 365

『슬램덩크』의 장면을 따라가며 **1년(365일) 동안 매일 20~30분** 공부하는 일본어 회화 과정입니다.
사쿠라기가 농구 초보에서 산노전까지 성장하는 1년처럼, 히라가나부터 시작해 **말하기·듣기·쓰기**를 함께 키웁니다.

## 목표 수준

| 시점 | 도달 목표 | 대략적 수준 |
|---|---|---|
| 3개월 (13주) | 가나 읽고 쓰기, 자기소개, 좋아하는 것·하루 일과를 です/ます로 말하기 | JLPT N5 입문 |
| 6개월 (26주) | て형·반말을 써서 친구와 짧은 대화, 쇼핑·약속·몸 상태 말하기 | N5 ~ N4 |
| 9개월 (39주) | 비교·조건·이유를 붙여 내 생각 말하기, 1분 스피치 | N4 |
| 12개월 (52주) | 수동·사역·주고받기, 편지와 400자 작문, 3분 발표 | N4 ~ N3 |

**"초등학교 6학년 수준"에 대해:** 일본 초등 6학년 아이는 6년 동안 일본어 속에서 자라며 한자 1,026자를 배웁니다.
그래서 1년 만에 그 수준과 똑같아지기는 현실적으로 어렵습니다. 이 과정은 **일본 초등 고학년 아이와 학교·운동·취미 같은 일상 화제로 막힘없이 대화하고, 그 아이가 쓰는 정도의 짧은 글(일기·편지)을 쓰는 것**을 목표로 합니다.
한자는 초등 1~3학년 한자를 중심으로 약 300~400자를 자연스럽게 익히게 됩니다.

## 구성

```
index.html        ← 매일 여는 학습 앱 (음성 듣기·받아쓰기 채점·역할극·진도 기록)
weeks/            ← 주차별 학습지 52개 + 최종평가 (인쇄용 마크다운)
data/q1~q4.json   ← 원본 데이터 (분기별 13주)
data/syllabus.md  ← 1년 실라버스 (장면 × 문법)
build.py          ← data/*.json → app/data.js, weeks/*.md 생성
```

매주 1개의 장면을 다루며, 장면마다 다음 자료가 들어 있습니다.
**단어 10 · 문법 1 (예문 4) · 핵심표현 5 · 대화문 8~10줄 · 듣기 퀴즈 3 · 받아쓰기 3 · 말하기 과제 · 쓰기 과제(모범 답안)**

## 하루 루틴 (일주일 = 장면 1개)

| 요일 | 주제 | 하는 일 | 시간 |
|---|---|---|---|
| 1일 | 장면·단어 | 장면 읽기, 단어 듣고 따라 하기, (1분기) 가나 쓰기 | 20분 |
| 2일 | 문법·핵심표현 | 문법 이해 → 나에 관한 예문 3개 쓰기 | 25분 |
| 3일 | 듣기 | 대본 없이 2번 듣기 → 퀴즈 → 대본 확인 | 20분 |
| 4일 | 쉐도잉 | 한 줄씩 따라 하기 → 겹쳐 말하기 → 한국어 보고 말하기 | 25분 |
| 5일 | 말하기 | 캐릭터 역할극, 1분 녹음, 고칠 점 메모 | 25분 |
| 6일 | 받아쓰기·쓰기 | 받아쓰기 3문장, 작문, 모범 답안과 비교 | 30분 |
| 7일 | 주간 복습 | 단어 테스트, 대화문 외워 말하기, 지난주 복습, 자기평가 | 25분 |

52주 × 7일 = 364일, **365일째는 최종 평가**(무작위 듣기 5개, 받아쓰기 10개, 3분 발표, 400자 작문)입니다.

## 사용 방법

1. **앱 열기**
   - 가장 쉬운 방법: 저장소 Settings → Pages → Branch를 이 브랜치(또는 main)로 지정하면 `https://<아이디>.github.io/file02/` 에서 휴대폰으로 바로 열 수 있습니다.
   - 또는 저장소를 내려받아 `index.html`을 브라우저로 엽니다 (인터넷 없이도 동작, 글꼴만 기본 글꼴로 바뀜).
2. 아래쪽 **설정 → 학습 시작일**을 넣으면 매일 그날 분량이 자동으로 열립니다.
3. 🔊 버튼은 기기의 일본어 음성(TTS)을 씁니다. 소리가 안 나면 휴대폰/PC 설정에서 **일본어 음성**을 설치하세요. 속도는 처음엔 ×0.8, 익숙해지면 ×1.0 이상으로.
4. 할 일을 체크하면 진도표에 기록됩니다. 기록과 작문은 **그 기기의 브라우저에만** 저장되니, 한 기기로 꾸준히 쓰는 게 좋습니다.
5. 종이로 공부하고 싶다면 `weeks/` 폴더의 학습지를 인쇄하세요.

## 효과를 높이는 팁

- **소리 내기가 핵심입니다.** 눈으로만 보는 날을 만들지 마세요. 모든 문장은 최소 3번 입으로 말합니다.
- **녹음 파일을 지우지 마세요.** 5일차마다 녹음을 남겨 두면 13주·26주·39주·52주에 1주차와 비교하며 성장을 확인할 수 있습니다.
- **밀려도 건너뛰지 마세요.** 하루 빠지면 다음 날 이어서 하면 됩니다(시작일을 하루 뒤로 바꾸면 됨). 7일차 복습만큼은 꼭 하세요.
- **3분기부터는 원작을 같이 보세요.** 일본어판 『SLAM DUNK』를 하루 2~3쪽씩 소리 내어 읽으면, 이미 아는 장면이라 처음 보는 표현도 뜻을 짐작하기 쉽습니다.
- **분기 끝 주(13·26·39·52주)는 점검 주간입니다.** 자기평가 점수가 3 미만인 영역이 있으면 그 분기에서 가장 어려웠던 2주를 한 번 더 돌고 넘어가도 괜찮습니다.

## 자료 수정하기

`data/q1.json` ~ `data/q4.json`을 고친 뒤 `python3 build.py`를 실행하면 앱 데이터(`app/data.js`)와 학습지(`weeks/`)가 다시 만들어집니다. 데이터 형식은 `data/SPEC.md`를 보세요.
