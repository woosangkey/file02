# N1 합격노트 — JLPT N1 365일 완성

**2027년 12월 JLPT N1 합격**을 목표로, 하루 40~60분씩 1년 동안 공부하는 학습 앱입니다.
[주술회전 일본어노트](https://woosangkey.github.io/jp-note/)와 같은 화면 구성(진도판·승급·단어 카드·복습·모의·인쇄 워크북)으로 만들었습니다.

## 일정

| 항목 | 날짜 |
|---|---|
| Day 1 (기본값, 앱 설정에서 변경 가능) | 2026-11-02 (월) |
| (선택) 7월 JLPT — 중간 점검 응시 | 2027-07-04 (일) · Day 245 |
| Day 365 졸업 모의고사 | 2027-11-01 |
| **목표 시험: 12월 JLPT N1** | **2027-12-05 (일)** |

JLPT는 매년 7월·12월 첫째 일요일에 치러집니다. 시험일과 접수 기간(7월 시험은 보통 3~4월, 12월 시험은 8~9월)은 JLPT 한국 공식 사이트에서 꼭 다시 확인하세요.
Day 365 이후 시험까지 남는 약 5주는 월말 모의(Day 30·60·…·360)와 졸업 모의고사를 다시 풀고, 어휘 복습을 매일 하는 기간입니다.

## 1년 구성

| 단계 | Day | 내용 | 시험 파트 |
|---|---|---|---|
| 1단계 | 1–90 | N1 문법 기초 (시간·계기 / 역접·조건 / 정도·강조) | 文法形式の判断 · 文の組み立て · 文脈規定 · 漢字読み |
| 2단계 | 91–180 | N1 문법 심화 (상태·기준 / 문어 강조 / 문장 흐름) | 言い換え類義 · 用法 · 文章の文法 |
| 3단계 | 181–270 | 독해 실전 (접속사 논리 / 주장 표현 / 비즈니스 경어) | 内容理解 · 統合理解 · 情報検索 · 主張理解 |
| 4단계 | 271–360 | 청해 집중 + 혼동 문법 비교 + 빈출 문법 최종 정리 | 課題 · ポイント · 概要 · 即時応答 · 統合理解 |
| 마무리 | 361–365 | 시험 전략 (시간 배분 · 청해 메모법 · 최종 점검) + 졸업 모의고사 30제 | 전 파트 |

월별 상세 계획은 [`data/SYLLABUS.md`](data/SYLLABUS.md)에 있습니다.

## 하루 공부 (7단계)

1. **오늘의 지문 (読解)**: N1 수준 칼럼·기사·안내문을 시간 재며 읽기 → 해석 확인
2. **청해·섀도잉**: 2~3명이 나오는 짧은 대화를 듣고 한 줄씩 3번 따라 말하기 (4단계에는 스크립트를 가리고 들음)
3. **N1 어휘 8개**: 카드를 뒤집어 읽기·뜻 확인 → 완료하면 간격 반복 복습함(1→2→4→8…일)에 자동으로 들어감
4. **문법 한 컷**: 접속 형태, 뉘앙스, 시험에 나오는 함정, 예문 3개
5. **헷갈리는 표현 구별**: 비슷한 표현과 나란히 비교
6. **쓰기·말하기 미션**: 오늘 문법으로 직접 쓰기(자동 저장) + 녹음
7. **JLPT형 문제 3개**: 문법 / 어휘 / 독해 또는 청해 — 다 맞히면 그날 완료

- **7일마다 주간 복습**: 어휘·문법 10문제 + 그 주의 대화 몰아서 듣기
- **30일마다 월말 모의**: 문자·어휘·문법 20문제 + 독해·청해 다시 풀기 + 그달 틀렸던 날 목록
- **Day 365 졸업 모의고사**: 30문제를 풀면 구분별 점수(60점 만점 환산)와 합격 기준(총점 100 이상, 각 구분 19 이상) 판정

## 사용 방법

1. GitHub Pages로 연 주소를 휴대폰·아이패드 **Safari/Chrome**에서 엽니다.
2. 공유 버튼 → **홈 화면에 추가**하면 앱처럼 쓸 수 있고, 한 번 연 화면은 오프라인에서도 열립니다.
3. 맨 아래 **설정 → 시작일**을 실제로 시작하는 날로 맞추세요.
4. 🔊 음성은 앱에 들어 있는 음성 파일로 재생돼요(무음 모드에서도 재생). 속도는 「느리게 → 보통 → 빠르게(실전)」.
5. 진도·작문·녹음은 **그 기기의 브라우저에만** 저장됩니다. 한 기기로 꾸준히 쓰세요.
6. 설정의 🖨 버튼으로 한 달 분량 워크북을 인쇄(또는 PDF 저장)할 수 있습니다.

## GitHub Pages 켜기

저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 Save. 1~3분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

## 자료 수정하기

```
data/mNN.json     ← 원본 (한 달 = 한 파일, 키는 Day 번호)
data/final.json   ← Day 365 졸업 모의고사
python3 check.py  ← 형식 검사
python3 build.py  ← data/*.json → data/*.js (앱이 읽는 파일)
python3 gen_audio.py [Day...]   ← 음성 다시 만들기 (pip install pyopenjtalk-plus numpy, ffmpeg 필요)
```
데이터를 고친 뒤에는 `sw.js`의 `VERSION` 숫자를 올려야 홈 화면 앱에도 새 내용이 반영됩니다.

## 알아 둘 점

- 모든 지문·대화·문제는 학습용으로 새로 쓴 것이며 실제 기출문제가 아닙니다. 4단계부터는 **JLPT 공식 문제집**(일본국제교육지원협회 발행)도 꼭 함께 풀어 보세요.
- 음성은 음성합성(Open JTalk)이라 실제 시험 음성보다 억양이 단조롭습니다.
- 전제 수준: N2 합격 또는 그에 가까운 실력. N3 이하라면 N2 과정을 먼저 하거나 1단계를 천천히 두 번 도세요.
