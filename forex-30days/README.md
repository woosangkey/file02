# 외환 30일 완성 — 투자 & 상담역 과정

> 하루 30분, 30일 동안 **외환의 기본 원리 → 시장 읽는 법 → 상품과 헤지 → 고객 상담 실전**까지 익히는 학습 자료입니다.
> 목표: ① 내 돈의 환위험을 스스로 판단하는 투자자, ② 고객에게 외환 상품을 정확하고 적합하게 설명하는 상담역.

## 하루 30분 사용법

| 시간 | 할 일 |
|---|---|
| 0–12분 | **핵심 개념** 읽기 |
| 12–20분 | **예시·계산**을 손으로 직접 따라 하기 |
| 20–25분 | **투자자 / 상담역 포인트** 정리 → 노트에 한 줄 요약 |
| 25–30분 | **확인 문제** 풀고 정답 확인 (정답은 펼쳐서 보기) |

> 팁: 매일 아침 USD/KRW, 달러인덱스(DXY), 미국 10년물 금리 3개 숫자를 기록하세요. 30일 뒤에는 스스로 만든 '시장 일지'가 생깁니다.

## 꼭 알아둘 점

- 예시에 나오는 환율·금리 숫자는 **계산 연습용 가정값**입니다. 실제 수치는 한국은행 경제통계시스템(ECOS), 서울외국환중개, 각 은행 고시 환율에서 확인하세요.
- 세법, 예금자보호 한도, 규제는 바뀔 수 있습니다. 상담에 쓰기 전에 국세청, 예금보험공사, 금융감독원에서 **최신 기준을 꼭 다시 확인**하세요. (이 자료는 2026년 10월 기준으로 작성했습니다.)
- 이 자료는 학습용이며 특정 상품의 투자를 권유하지 않습니다.
