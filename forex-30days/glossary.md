## 핵심 공식

| 공식 | 내용 | 배운 날 |
|---|---|---|
| 환율 변화율 | (새 환율 − 기존 환율) ÷ 기존 환율 | Day 2 |
| 우대 적용 환율 | 매매기준율 ± 스프레드 × (1 − 우대율) | Day 2 |
| 절대적 PPP | 환율 = 국내 물가 ÷ 해외 물가 | Day 4 |
| 상대적 PPP | 환율 변화율 ≈ 국내 물가상승률 − 해외 물가상승률 | Day 4 |
| 선물환율 (CIP) | F = S × (1 + i원 × t) ÷ (1 + i달러 × t) | Day 5 |
| 스왑포인트 근사 | F − S ≈ S × (i원 − i달러) × t | Day 5 |
| 재정환율 | 원/100엔 = USD/KRW ÷ USD/JPY × 100 | Day 11 |
| 콜옵션 손익분기 | 행사가 + 프리미엄 | Day 17 |
| 풋옵션 손익분기 | 행사가 − 프리미엄 | Day 17 |
| 원화 기준 수익률 | (1 + 자산 수익률) × (1 + 환율 변화율) − 1 | Day 18 |
| 해외주식 양도세 | (원화 환산 차익 − 250만 원) × 22% | Day 20 |
| 레버리지 손실률 | 환율 변동률 × 레버리지 배수 | Day 25 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 간접표시법 | 자국 통화 1단위를 외화로 표시 (예: EUR/USD) |
| 경상수지 | 상품·서비스·본원소득·이전소득 거래의 수지 |
| 구두 개입 | 외환당국이 발언으로 시장 쏠림을 경고하는 것 |
| 금융계정 | 직접·증권·파생·기타투자와 외환보유액 변동 기록 |
| 금융소득종합과세 | 이자·배당 소득이 연 2,000만 원을 넘으면 초과분을 종합소득에 합산 |
| 기준통화 | 통화쌍의 앞쪽 통화 (USD/KRW의 USD) |
| 녹아웃(Knock-out) | 환율이 특정 수준에 닿으면 옵션이 소멸 |
| 녹인(Knock-in) | 환율이 특정 수준에 닿으면 옵션이 효력 발생 |
| 달러인덱스(DXY) | 6개 주요 통화 대비 달러 가치 지수 |
| 디스카운트 | 선물환율 < 현물환율 |
| 매매기준율 | 은행 환율의 기준이 되는 환율 |
| 매파 / 비둘기파 | 긴축 선호 / 완화 선호 |
| 스무딩 오퍼레이션 | 환율 급변을 완화하기 위한 당국의 시장 개입 |
| 스왑포인트 | 선물환율 − 현물환율 |
| 스프레드 | 매수·매도 가격 차이 (은행 마진) |
| 실질실효환율(REER) | 물가와 교역 비중을 반영한 종합 환율 지수 |
| 외환보유액 | 통화당국이 보유한 대외 지급 준비 자산 |
| 외환스왑 | 현물환과 반대 방향 선물환을 동시에 거래 |
| 위험통화 | 위기 때 약해지는 통화 (원화, 호주달러 등) |
| 안전통화 | 위기 때 강해지는 통화 (달러, 엔, 스위스프랑) |
| 재정환율 | 달러를 거쳐 계산한 제3통화 환율 |
| 직접표시법 | 외화 1단위를 자국 통화로 표시 (예: 1달러 = 1,400원) |
| 캐리 트레이드 | 저금리 통화로 빌려 고금리 자산에 투자 |
| 콜옵션 / 풋옵션 | 살 권리 / 팔 권리 |
| 통화스왑(CRS) | 두 통화의 원금과 이자를 교환하는 장기 계약 |
| 프리미엄 (선물환) | 선물환율 > 현물환율 |
| 프리미엄 (옵션) | 옵션을 사는 대가로 내는 가격 |
| 환노출(UH) | 환헤지를 하지 않아 환율 변동을 그대로 받는 상태 |
| 환헤지(H) | 선물환 등으로 환율 변동 위험을 줄이는 것 |
| CIP / UIP | 무위험 금리평가 / 커버되지 않은 금리평가 |
| FOMC | 미국 연방공개시장위원회 (연 8회) |
| NDF | 차액결제선물환. 원금 없이 차액만 달러로 결제 |
| PPP | 구매력평가 |
| Risk-on / Risk-off | 위험선호 / 위험회피 국면 |
| VIX | 미국 주식시장 변동성 지수 (공포지수) |
