## 6. 공통 작성 규칙
- 출력 형식: JSON (스키마는 /home/user/file02/divbook/UNIT_SCHEMA.md). 블록 정의는 /home/user/file02/book/CHAPTER_SCHEMA.md 와 동일(p, h2, bullets, table, chart, callout, formula). 
- 사례 인물은 목차에 있는 이름·나이·직업 그대로 쓰되 **가상 각색 사례**임을 전제(본문에 「※ 사례는 이해를 돕기 위해 재구성했습니다」는 각 실전마당 첫 사례에 한 번).
- 모든 계산(분배금, 세금, 원금 추이, 건보료 영향 등)은 python으로 검산. 계산 가정은 표 아래 캡션에 적는다.
- 차트·표 수치가 실측이 아니면 「(예시)」「(가상 시나리오)」. 수익·분배 보장, 「무조건」, 「확정」 같은 단정 금지. 매 단위마다 투자 위험(원금 손실 가능, 분배금 변동·감소 가능) 언급 1회.
- 문단 200~400자. 독자에게 말 거는 문체. 표·체크리스트 적극 활용.
- JSON 문자열 안 큰따옴표 금지(「」, ' 사용). chart series 길이 = x 길이, pie 는 series 1개.
- 임시 스크립트는 scratchpad 아래 자기 단위 이름 폴더(예: scratchpad/div_p1/)에.
- 작성 후 json.load·글자수·series 길이 검증. 최종 응답은 파일명, 본문 글자수, 블록 구성 한 줄.
