## 핵심 공식

| 공식 | 내용 | 배운 날 |
|---|---|---|
| 단순 수익률 | 끝 가격 ÷ 시작 가격 − 1 | Day 5 |
| 12-1 모멘텀 | 1개월 전 가격 ÷ 12개월 전 가격 − 1 | Day 3, 5 |
| 연환산 수익률 | (1 + 기간 수익률)^(12 ÷ 개월 수) − 1 | Day 5 |
| 로그 수익률 | ln(끝 가격 ÷ 시작 가격), 기간별로 더해서 합침 | Day 5 |
| 단순 이동평균 | 최근 N기간 종가의 합 ÷ N | Day 6 |
| 52주 고점 근접도 | 현재가 ÷ 52주 최고가 | Day 6 |
| 필터 밴드 | 재진입: 이동평균 × (1 + 밴드), 이탈: 이동평균 × (1 − 밴드) | Day 10 |
| 서프라이즈율 | (발표 실적 − 컨센서스) ÷ 컨센서스 | Day 13 |
| SUE | (발표 실적 − 예상 실적) ÷ 과거 서프라이즈의 표준편차 | Day 13 |
| 손실 회복 수익률 | 1 ÷ (1 − 손실률) − 1 | Day 15 |
| 변동성 연환산 | 일간 변동성 × √252 ≈ 월간 변동성 × √12 | Day 16 |
| 변동성 조절 비중 | 목표 변동성 ÷ 최근 실현 변동성 (상한 100% 권장) | Day 16 |
| 트레일링 스톱 | 매수 후 최고가 × (1 − 스톱 비율) | Day 17 |
| 위험 기반 매수 수량 | (계좌 × 1회 위험 비율) ÷ (매수가 − 손절가) | Day 18 |
| 연간 거래비용 | 연간 회전율 × 왕복 비용 | Day 19 |
| 우연히 하나라도 통과할 확률 | 1 − (1 − 유의수준)^시험 횟수 (독립 가정) | Day 20 |
| 2자산 50:50 변동성 | √(0.25σ₁² + 0.25σ₂² + 2 × 0.25 × ρσ₁σ₂) | Day 25 |
| 기대값 | 승률 × 평균 이익 − (1 − 승률) × 평균 손실 | Day 29 |
| R 배수 | 거래 손익 ÷ 1회 위험 금액 | Day 29 |

## 용어집 (가나다순)

| 용어 | 뜻 |
|---|---|
| 골든크로스 / 데드크로스 | 단기 이동평균이 장기 이동평균을 위로 / 아래로 뚫는 것 |
| 과소반응 | 새로운 정보를 가격에 한 번에 다 반영하지 않는 경향, 모멘텀의 행동재무 설명 |
| 과최적화 | 과거 데이터에 지나치게 맞춰 실전에서 재현되지 않는 규칙을 만드는 것 |
| 군집 행동 | 다른 투자자를 따라 같은 방향으로 매매하는 행동 |
| 기대값 | 거래 한 번당 평균적으로 기대되는 손익 |
| 단기과열종목 | 거래량·변동성이 갑자기 커져 단일가 매매 등이 적용될 수 있는 종목 |
| 단기 반전 | 최근 1주~1개월 많이 오른 종목이 되돌림을 보이는 경향 |
| 듀얼 모멘텀 | 상대 모멘텀으로 고르고 절대 모멘텀으로 거르는 전략 (안토나치, 2014) |
| 로그 수익률 | 가격 비율의 자연로그, 여러 기간을 더해서 합칠 수 있음 |
| 리밸런싱 | 정해진 주기에 규칙대로 보유 자산과 비중을 다시 맞추는 것 |
| 매니지드 퓨처스 | 여러 자산의 선물로 주로 추세추종을 하는 운용 방식 (CTA) |
| 모멘텀 | 최근 강했던 자산이 한동안 더 강한 경향 |
| 모멘텀 크래시 | 모멘텀 전략이 짧은 기간 매우 큰 손실을 보는 현상, 주로 급반등기 |
| 미래 정보 사용(룩어헤드 편향) | 백테스트에서 그 시점에 알 수 없던 정보를 쓰는 오류 |
| 백테스트 | 과거 데이터로 투자 규칙을 시험하는 것 |
| 변동성 조절 | 실현 변동성에 따라 비중을 조절해 위험을 일정하게 유지하는 방법 |
| 상대 모멘텀 | → 횡단면 모멘텀 |
| 생존 편향 | 사라진 종목을 빼고 살아남은 종목만 분석해 성과가 부풀려지는 편향 |
| 섹터 로테이션 | 섹터별 모멘텀 순위에 따라 투자 섹터를 교체하는 전략 |
| 손익비 | 평균 이익 ÷ 평균 손실 |
| 시계열 모멘텀 | 자산의 과거 수익률(또는 현금 대비)로 추세를 판단하는 모멘텀, 절대 모멘텀 |
| 시장경보 제도 | 한국거래소가 투기·이상 거래 종목을 투자주의·투자경고·투자위험으로 지정해 알리는 제도 |
| 어닝 서프라이즈 | 발표 실적이 시장 예상(컨센서스)과 크게 다른 것 |
| 유사투자자문업 | 불특정 다수에게 간행물·방송 등으로 투자 정보를 제공하는 신고 업종, 1:1 자문 불가 |
| 이동평균 | 최근 일정 기간 가격의 평균, 추세 판단에 사용 |
| 이익 모멘텀 | 실적 추정치 상향·어닝 서프라이즈처럼 이익이 좋아지는 힘 |
| 장기 반전 | 3~5년 동안 많이 오른 종목이 이후 부진한 경향 |
| 절대 모멘텀 | → 시계열 모멘텀 |
| 처분효과 | 오른 주식은 빨리 팔고 내린 주식은 오래 붙드는 경향 |
| 추세추종 | 가격 추세를 따라 매수·매도하는 시계열 모멘텀 전략 |
| 터틀 트레이더 | 1983년 리처드 데니스가 교육한 초보 트레이더 집단 |
| 트레일링 스톱 | 매수 후 최고가를 따라 올라가는 손절선 |
| 팩터 ETF | 가치·모멘텀 등 특정 팩터로 종목을 고르는 지수를 추종하는 ETF (스마트 베타) |
| 포지션 사이징 | 한 종목·한 번의 거래에 투입할 수량을 정하는 규칙 |
| 회전율 | 일정 기간 매매 금액이 포트폴리오 규모의 몇 배인지 나타내는 지표 |
| 횡단면 모멘텀 | 여러 자산을 서로 비교해 강한 것을 고르는 모멘텀, 상대 모멘텀 |
| 휩소 | 추세 신호가 짧은 기간에 반복해서 뒤집히며 손실·비용이 쌓이는 현상 |
| 12-1 모멘텀 | 12개월 전부터 1개월 전까지의 수익률 (최근 1개월 제외) |
| 52주 신고가 | 최근 1년 중 가장 높은 가격 |
| ATR | 평균 진폭(Average True Range), 변동성 기반 손절·사이징에 사용 |
| CTA | 상품투자자문업자(Commodity Trading Advisor), 선물 추세추종 운용사 |
| GEM | 안토나치의 글로벌 주식 모멘텀(Global Equities Momentum) 전략 |
| GTAA | 전술적 자산배분(Global Tactical Asset Allocation), 파버의 10개월 이동평균 규칙 |
| PEAD | 실적 발표 후 주가 표류(Post-Earnings-Announcement Drift) |
| R 배수 | 거래 손익을 1회 위험 금액(1R)으로 나눈 값 |
| SUE | 표준화 예상외 이익(Standardized Unexpected Earnings) |
