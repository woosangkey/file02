band: 신문과 증권 앱이 술술 읽히는 핵심 용어 108개
---

경제 기사를 읽다가 'PER', '듀레이션', '괴리율' 같은 단어에서 멈칫한 적이 있을 것이다. 투자의 세계는 용어가 절반이다. 뜻을 정확히 몰라도 대충 넘어갈 수는 있지만, 그러다 보면 기사의 핵심을 놓치고 남의 해석에 기대게 된다. 이 별첨은 본문에서 다룬 용어와 신문·증권 앱에서 자주 마주치는 용어 108개를 **주제별로 묶어 한 줄로** 정리했다. 처음부터 외우려 하지 말고, 모르는 단어가 나올 때마다 사전처럼 펼쳐 보자. 각 표 안에서는 가나다순(영문 약어는 끝)으로 배열했다.

### 경제·금리

<p class="caption">[표 A-2-1] 경제·금리 용어</p>

| 용어 | 한 줄 정의 |
|---|---|
| 경기선행지수 | 앞으로 경기가 좋아질지 미리 보여 주는 지표 묶음 |
| 국내총생산(GDP) | 한 나라 안에서 1년간 새로 만든 부가가치의 합 |
| 근원물가 | 변동이 큰 식료품·에너지를 뺀 물가 |
| 기준금리 | 중앙은행이 정하는, 모든 금리의 기준이 되는 금리 |
| 기축통화 | 국제 거래에서 기본으로 쓰이는 통화(현재 달러) |
| 디플레이션 | 물가가 지속적으로 떨어지는 현상 |
| 명목금리 | 물가를 고려하지 않은 겉으로 보이는 금리 |
| 물가상승률 | 소비자물가가 1년 전보다 오른 비율 |
| 법정화폐 | 금과 바꿔 주지 않고 국가 신용으로 쓰는 돈 |
| 부분지급준비제도 | 은행이 예금 일부만 남기고 나머지를 대출하는 제도 |
| 스태그플레이션 | 경기 침체와 물가 상승이 함께 오는 상황 |
| 실질금리 | 명목금리에서 물가상승률을 뺀 금리 |
| 양적완화(QE) | 중앙은행이 채권을 사들여 돈을 푸는 정책 |
| 인플레이션 | 돈의 가치가 떨어져 물가가 오르는 현상 |
| 장단기 금리차 | 장기 금리 − 단기 금리, 역전 시 경기 둔화 신호 |
| 통화량(M2) | 현금·예금 등 시중에 풀린 돈의 양 |
| 환율 | 다른 나라 돈 1단위를 사는 데 드는 원화 금액 |
| 72의 법칙 | 72 ÷ 연 수익률(%) ≈ 원금이 두 배가 되는 햇수 |
| CPI | 소비자물가지수, 가계가 사는 물건값의 변화 |
| FOMC | 미국 기준금리를 정하는 연방공개시장위원회 |
:::

### 주식

::: tbl
<p class="caption">[표 A-2-2] 주식 용어</p>

| 용어 | 한 줄 정의 |
|---|---|
| 공모주 | 상장 전 일반 투자자에게 청약으로 파는 주식 |
| 공시 | 기업이 투자자에게 알려야 할 정보를 공개하는 것 |
| 균등배정 | 공모주를 최소 증거금 낸 청약자에게 똑같이 나누는 방식 |
| 매출액 | 기업이 물건·서비스를 팔아 번 돈의 총액 |
| 배당성향 | 순이익 중 배당으로 나눠 준 비율 |
| 배당수익률 | 주가 대비 1년 배당금의 비율 |
| 배당락일 | 이날부터 사면 이번 배당을 받지 못하는 날 |
| 보통주 | 의결권이 있는 일반적인 주식 |
| 부채비율 | 부채 ÷ 자기자본, 재무 안정성 지표 |
| 시가총액 | 주가 × 발행주식 수, 기업의 시장 가치 |
| 영업이익 | 매출에서 원가·판매관리비를 뺀 본업 이익 |
| 우선주 | 의결권 대신 배당을 더 주는 주식 |
| 유보율 | 쌓아 둔 이익잉여금 등이 자본금의 몇 배인지 |
| 유상증자 | 돈을 받고 새 주식을 발행해 자본을 늘리는 것 |
| 의무보유확약 | 기관이 공모주를 일정 기간 팔지 않겠다는 약속 |
| 당기순이익 | 모든 비용과 세금을 뺀 최종 이익 |
| BPS | 주당순자산, 순자산 ÷ 주식 수 |
| EPS | 주당순이익, 순이익 ÷ 주식 수 |
| PBR | 주가 ÷ BPS, 1 미만이면 장부가보다 싸다는 뜻 |
| PER | 주가 ÷ EPS, 이익 대비 주가 수준 |
| ROE | 자기자본이익률, 순이익 ÷ 자기자본 |
| 서킷브레이커 | 지수 급락 시 거래를 일시 멈추는 장치 |
:::

<div class="box">
<div class="box-title">머니 포인트 | 숫자 용어를 한 번에 잇는 공식</div>
<ul>
<li><strong>PER × EPS = 주가</strong> 이익이 같다면 PER이 높을수록 비싸게 거래된다.</li>
<li><strong>PBR × BPS = 주가</strong> 순자산 대비 몇 배에 거래되는지 본다.</li>
<li><strong>ROE = PBR ÷ PER</strong> 세 지표는 서로 연결되어 있다(2-4).</li>
</ul>
</div>

### 채권

::: tbl
<p class="caption">[표 A-2-4] 채권 용어</p>

| 용어 | 한 줄 정의 |
|---|---|
| 국고채 | 정부가 발행하는 가장 안전한 채권 |
| 듀레이션 | 금리 1%p 변화에 채권값이 변하는 정도(년) |
| 만기 | 원금을 돌려받기로 약속한 날 |
| 만기수익률(YTM) | 만기까지 보유할 때 얻는 연 수익률 |
| 신용등급 | 원리금을 갚을 능력을 AAA~D로 매긴 등급 |
| 쿠폰(표면금리) | 채권에 적힌, 액면가 대비 연 이자율 |
| 액면가 | 만기에 돌려받는 채권의 원금 |
| 저쿠폰 채권 | 표면금리가 낮아 이자 세금이 적은 채권 |
| 하이일드 채권 | 신용등급이 낮은 대신 금리가 높은 채권 |
| 회사채 | 기업이 돈을 빌리려고 발행하는 채권 |
| 신종자본증권 | 만기가 길거나 없는, 자본 성격의 채권 |
| 발행어음 | 대형 증권사가 자기 신용으로 발행하는 단기 어음 |
| 금리↑ 채권값↓ | 금리가 오르면 기존 채권 가격은 떨어진다 |
| 스프레드 | 회사채 금리 − 국고채 금리, 신용위험의 값 |
:::

### 차트

::: tbl
<p class="caption">[표 A-2-6] 차트 용어</p>

| 용어 | 한 줄 정의 |
|---|---|
| 거래량 | 일정 기간 거래된 주식 수 |
| 골든크로스 | 단기 이동평균선이 장기선을 위로 뚫는 것 |

| MDD | 고점 대비 최대 하락률 |
:::

용어를 아는 것과 투자를 잘하는 것은 다르다. 그러나 용어를 모르면 판단의 재료 자체를 읽을 수 없다. 이 사전에 없는 단어를 만나면 여백에 직접 한 줄 정의를 적어 넣어 보자. 그렇게 나만의 사전이 두꺼워질수록 뉴스와 공시가 '정보'로 바뀐다.
