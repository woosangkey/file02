# 원고 작성 가이드 — 『처음 만나는 재테크 교과서』

모든 꼭지는 `content/<섹션ID>.md` 한 파일. **반드시 `content/1-1.md`를 먼저 읽고** 문체·구성·컴포넌트 사용법을 그대로 따른다.

## 1. 파일 형식
```
title: 앞줄(얇게)|뒷줄(굵게)        ← 꼭지 제목을 2줄로 나눔. 목차 제목과 같은 뜻
band: 파란 띠에 들어갈 부제 한 줄(25자 안팎, 꼭지마다 고유해야 함 — 쪽번호 계산에 사용)
---
본문 마크다운
```
- 제목/부제에 `:` 사용 가능(첫 번째 콜론만 키 구분).
- 따옴표는 곧은 따옴표('…', "…")로 쓰면 빌드가 둥근 따옴표로 바꿔 준다.

## 2. 분량과 구성 (꼭지당 신국판 6~8쪽 ≈ 본문 6,500~9,000자)
1. 도입 1~2문단: 일상 장면·질문으로 시작(1-1의 "만 원짜리 지폐" 처럼).
2. `### 소제목` 4~6개: 개념 → 원리 → 숫자 예시 → 실전 방법 순서. 목차의 세부 항목(toc.py의 세 번째 값)은 **빠짐없이 소제목으로** 다룬다.
3. **이미지·표 정리 최소 3개 이상** (사용자 요청 핵심!):
   - `한눈에 보기` 인포그래픽 박스 **1~2개 필수**
   - 마크다운 표 1개 이상(캡션 `[표 x-y]`, 아래 3-2 참고)
   - 필요하면 SVG 그림 1개(`[그림 x-y]`)
4. `머니 포인트` 박스 1~2개.
5. 마지막은 반드시 `한 줄 정리` 박스(요약 1~2문장 + **오늘의 실천** 1개).

## 3. 컴포넌트 (HTML 그대로 붙여 넣기, 빈 줄로 앞뒤 구분)

### 3-1. 머니 포인트 / 한 줄 정리
```html
<div class="box">
<div class="box-title">머니 포인트 | 제목</div>
<ul><li><strong>키워드</strong> 설명</li></ul>
</div>

<div class="box summary">
<div class="box-title">한 줄 정리</div>
<p>요약 문장.</p>
<p><strong>오늘의 실천</strong> 구체적 행동 하나.</p>
</div>
```

### 3-2. 표 (캡션과 표를 함께 묶기)
```
::: tbl
<p class="caption">[표 3-2] 표 제목</p>

| 구분 | A | B |
|---|---|---|
| … | … | … |
:::
```
표는 4열 이하, 셀 글자는 짧게(한 셀 25자 이내).

### 3-3. 한눈에 보기 (인포그래픽) — 아래 4가지 중 내용에 맞게 골라 사용
```html
<div class="glance"><div class="g-title">박스 제목</div><div class="g-body">
  ... 아래 레이아웃 중 하나 ...
<p class="g-note">→ 한 줄 해설(선택)</p>
</div></div>
```
- **흐름(단계)**: `<div class="flow"><div class="step"><b>1</b>짧은 설명</div> … </div>` (3~5단계, 단계당 15자 안팎)
- **카드 그리드**: `<div class="cards c2|c3|c4"><div class="card"><b>카드 제목</b>설명</div> … </div>`
  - 숫자 강조: `<div class="card"><b>제목</b><span class="big">5.5%</span>설명</div>`
- **비교(VS)**: `<div class="vs"><div class="side"><b>A</b><ul><li>…</li></ul></div><div class="mid">VS</div><div class="side alt"><b>B</b><ul><li>…</li></ul></div></div>`
- **체크리스트**: `<ul class="check"><li>항목</li></ul>`
- 박스 안에 표를 넣어도 된다(HTML `<table>` 사용).
- `<b>` 태그 안 텍스트는 굵은 제목으로 표시된다. 마크다운 문법은 HTML 블록 안에서 동작하지 않으니 HTML만 쓴다.

### 3-4. SVG 그림 (그래프·도식)
반드시 ```` ```{=html} ```` 펜스로 감싼다(안 감싸면 깨짐).
````
```{=html}
<figure>
<svg viewBox="0 0 600 220" xmlns="http://www.w3.org/2000/svg" font-family="Noto Sans CJK KR" font-size="13">
  ... 색상: 네이비 #2f4f9a, 진네이비 #1f3a7a, 연네이비 #6f88c4, 연배경 #eef2fa, 강조(금색) #b8862f, 회색 #666 ...
</svg>
<figcaption>[그림 3-1] 설명</figcaption>
</figure>
```
````
- 막대그래프, 꺾은선(예: 금리↑ 채권가격↓), 복리 곡선, 3층 연금 계단, 파이 대신 막대 등. 글자는 12px 이상, 텍스트가 상자 밖으로 넘치지 않게 좌표를 계산할 것.
- 수치 그래프는 실제/예시 값을 명시(예: "예시: 연 5%, 30년").

## 4. 문체
- 한국어 설명체 "~다". 친근하지만 가볍지 않게. 1인칭 '나'는 가끔만.
- **굵게**(`**…**`)는 문단당 1~2개 핵심어만. 영어 원어는 괄호로 1회.
- 계산 예시는 숫자를 실제로 계산해 맞는지 검증하고 쓴다.
- 특정 금융회사·개별 종목 '추천'은 하지 않는다. ETF는 "예: S&P500 추종 ETF"처럼 지수·유형으로 설명. 종목코드·상품명은 꼭 필요할 때만 '예시'로 표기.
- 투자 권유가 아닌 교육 목적임을 전제로, 위험도 반드시 함께 설명.

## 5. 사실 확인 (매우 중요)
- 세법·한도·요율·제도(ISA, 연금저축/IRP 세액공제, 금융소득종합과세, 청약 조건, 국민연금 보험료율·수령 나이, 예금자보호 한도, 공모주 제도, 해외주식 양도세 등)는 **WebSearch로 2026년 현행 기준을 확인**하고 쓴다. 확인 날짜 기준을 본문이나 표 아래 `g-note`/각주로 "2026년 10월 기준" 처럼 표기.
- 확신할 수 없는 수치는 범위·취지로 쓰고 "가입 전 금융사/국세청 확인" 문구를 붙인다. 지어내지 않는다.
- 꼭지 끝에 필요하면 `<div class="endnote"><p>※ 출처·기준: …</p></div>` 로 짧게 표기.
